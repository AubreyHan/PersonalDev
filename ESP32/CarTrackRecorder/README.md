# ESP32-S3 AMOLED 行车轨迹记录仪 (Car Track Recorder)

针对 **微雪 ESP32-S3-Touch-AMOLED-1.75-G**（1.75英寸 466×466 圆形 AMOLED，板载 Quectel LC76G 卫星定位、SDMMC 卡槽）定制的完整行车轨迹记录仪系统。

---

## 一、 功能特性矩阵

* 🖥️ **双界面与触摸滑屏**：
  - **高度显示界面**：实时海拔高度 (米)、最高/最低海拔统计卡片、每 5 秒滚动的行程海拔起伏历史折线图。
  - **轨迹显示界面**：自车居中显示、行驶轨迹航迹线实时绘制、根据车速自动缩放地图、右上角随时切换【航向朝上】与【正北朝上】视角模式、左上角动态指南针罗盘。
* 🕒 **全局顶部常驻状态栏**：
  - **实时走时**：GPS 纳秒级自动时区授时 + 板载 PCF85063 硬件 RTC。
  - **状态指示**：GPS 卫星颗数、录制状态红点（分段/持续）、等待定位待命标记、AP 状态指示。
* 🔘 **Boot 物理按键多态控制**：
  - **单击**：分段记录（熄火重新通电自动创建新文件）。
  - **双击**：持续记录（熄火重新通电自动追加写入旧文件）。
  - **再次按下**：停止记录并安全封存。
  - **长按 (>1.8秒)**：开启/关闭 Wi-Fi AP 与 HTTP Web 文件导出服务，屏幕弹出半透明 Toast 提示。
* 🛰️ **定位门禁（延迟就绪队列）**：
  - 未定位时按键进入待命模式（`ARMED`），一旦 3D Fix 锁定立即自动建档写入。
* 💾 **存储与数据安全**：
  - 1Hz 写入标准 `.gpx` 格式，以起始时间 `yyyymmdd-hhmmss.gpx` 命名。
  - 每满 1 小时自动切片为一个独立文件。
  - 写入即时 `fflush` 刷盘，具备断电保护机制。
  - TF 卡满盘先进先出（FIFO）自动淘汰清理最旧文件。
* 🌐 **无线 Web 文件导出**：
  - 手机连接板载热点 `Car-Tracker-GPX`，浏览器打开 `http://192.168.4.1`。
  - 查看 TF 卡剩余容量仪表盘，一键下载全部 `.gpx` 航迹文件。

## 二、 编译与烧录

基于 **ESP-IDF v5.3+ / v5.4+ / v5.5+** 构建：

```bash
cd CarTrackRecorder

# 1. 设置目标芯片为 ESP32-S3
idf.py set-target esp32s3

# 2. 编译项目 (组件管理器会自动拉取官方 BSP 与 LVGL 9)
idf.py build

# 3. 烧录并打开串口监视器 (请替换实际端口)
idf.py -p /dev/tty.usbmodem* flash monitor
```
