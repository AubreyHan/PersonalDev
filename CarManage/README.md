# 汽车维护与能耗记录管理系统 (我的车管家 · Car Care Tracker)

一个专为车主打造的多车辆能耗与维护记录应用，支持燃油车、纯电动车、混动车与增程车的全场景记录。

> 📖 **全景开发需求规格 (PRD) 与 Cloudflare 边缘自动化部署指南**：请参阅 [DEVELOPMENT_SPEC_AND_CF_DEPLOYMENT.md](DEVELOPMENT_SPEC_AND_CF_DEPLOYMENT.md)（含完整数学公式、表结构设计、全自动化部署脚本与 AI Vibe Coding 提示词模板）。

## 🌟 核心功能亮点

1. **多车辆精细化档案**
   - 支持录入与切换多台车辆。
   - 完整车辆参数支持：**车名/昵称、品牌、型号、动力形式、排量、油箱容量 (L)、电池容量 (kWh)、车牌号、初始里程 (km)、购车日期与备注**。
   - 各车辆数据完全隔离，支持设为当前常用车、编辑与删除。

2. **能耗分类录入**
   - 明确区分**油耗录入**与**电耗录入**，混动/增程车双能耗协同管理。
   - **油耗录入**：
     - 当前里程、加油量 (L)、单价 (元/L)、总价 (元)、油品标号 (92#/95#/98#/柴油等)、是否加满、加油站与备注。
   - **电耗录入**：
     - 当前里程、加电量 (kWh)、单价 (元/度)、总价 (元)、充电类型/规格 (快充 DC、慢充 AC、家用桩、品牌超充等)、起始与结束电量 (SOC %)、充电站与备注。

3. **智能联动计算器 (输入任意两项，自动推算第三项)**
   - 在油耗录入与电耗录入中：
     - 输入 **加油量/加电量** + **单价** ➔ 自动秒级算出 **总价**（保留2位小数）；
     - 输入 **总价** + **加油量/加电量** ➔ 自动反推 **单价**（保留3位小数）；
     - 输入 **总价** + **单价** ➔ 自动反推 **加油量/加电量**（保留2位小数）。
   - 界面实时显示 `✨ 自动计算` 徽标，并支持一键清空与手动复写，交互流畅无卡顿。

4. **独立能耗分析页面 (展示每两次补能间能耗与总能耗情况)**
   - **每两次补能之间的能耗流**：
     - 自动结算相邻两次加油/充电之间的**区间行驶里程 ($\Delta M$)**；
     - 精准计算**单次实际百公里能耗 ($L/100km$ 或 $kWh/100km$)**与**区间每公里成本 (元/km)**；
     - 自动对比整车综合均值，标记【优于均值/偏高/持平】视觉评级；
     - 显示补能时间、距上次补能天数、油站/电桩与规格。
   - **总能耗全局看板**：
     - 累计综合百公里油耗与电耗、总补能开销、综合每公里能耗成本；
     - 统计平均每次补能行驶里程与单次平均开销；
     - 极值荣誉榜：展示**历史最省区间（最低百公里能耗）**与**最高能耗峰值区间**；
     - 原生响应式 **SVG 补能能耗起伏走势折线图**。

5. **PWA 离线优先与多端安装 (地下车库无网畅快使用)**
   - 适配标准 **Progressive Web App (PWA)** 规范与 Web App Manifest。
   - **支持一键安装至桌面/主屏幕**：在 iPhone / iPad Safari 中点击“添加到主屏幕”，或在 Mac Chrome / Edge 中点击“安装应用”，即可获得纯净独立 App 沉浸体验（无浏览器地址栏干扰）。
   - **Service Worker 离线应用壳缓存**：静态页面、脚本、样式与图标已由 Service Worker 全量缓存，即使开启飞行模式或在地下负二层车库也能秒开秒用。
   - **本地 IndexedDB 存储引擎 (`db.js`)**：所有车辆档案、加油/加电/维保记录全部实时写入本地浏览器数据库，本地录入、修改、删除均瞬间完成，无需等待网络。

6. **Cloudflare D1 全球云端数据库双向自动同步**
   - 原生支持 **Cloudflare D1 (无服务器分布式 SQL)** + **Cloudflare Workers** 架构，**0 维护成本、永久免费**。
   - **智能 Outbox 同步队列**：离线状态下产生的操作排入本地队列，当设备重新连接 Wi-Fi 或蜂窝网络时，后台静默自动批量双向推送与拉取。
   - **多终端数据实时互通**：支持在 Mac 电脑、iPad 平板、iPhone 手机上共享同一套 Cloudflare D1 数据库，车主随时随地跨设备查验。
   - 顶部提供实时连接状态指示徽标（已同步 / 离线优先 / 同步中），并配备一键云端连接测试与手动同步弹窗。

7. **车辆维护与保养台账**
   - 记录常规保养（机油机滤）、刹车系统、轮胎动平衡、空调滤芯、年检验车、商业保险等支出。
   - 支持设置“下次建议保养里程”与“下次提醒日期”。

8. **智能化看板与数据分析**
   - 自动核算百公里平均油耗 ($L/100km$) 与 百公里平均电耗 ($kWh/100km$)。
   - 自动统计累计行驶里程、总花费金额、每公里综合使用成本（元/km）。
   - 提供全量历史明细流，支持按油耗/电耗/保养进行多维度分类筛选。

## 🚀 极简快速启动

系统基于 Python 原生内置标准库与现代 Web 前端构建，**无需安装任何第三方 pip 库或 node 依赖**，任何电脑均可开箱即用！

### 方式一：一键脚本启动 (推荐)

在项目目录下执行：
```bash
./start.sh
```
> 脚本将自动检测可用端口（默认 8088），启动服务并在系统默认浏览器中自动打开主界面。

### 方式二：命令行启动

```bash
python3 server.py 8088
```
打开浏览器访问：[http://127.0.0.1:8088](http://127.0.0.1:8088)

## ☁️ Cloudflare D1 云端同步配置

如需在多端（iPhone / iPad / Mac）使用云端数据库：
1. 参考 [Cloudflare 部署指南](file:///Users/aubreyhan/Tools/git_repo/PersonalDev/CarManage/cloudflare/deploy_guide.md) 创建 Cloudflare D1 数据库与 Worker 服务（全程可在 Cloudflare 网页端 3 分钟完成，无需本地配环境）。
2. 在应用右上角点击 **☁️ 云端同步** 按钮，填入您的 Worker 域名（如 `https://car-care-api.xxx.workers.dev`）并保存。
3. 点击“立即双向同步”，后续在任何设备打开都能自动同步最新记录！
