## 3. 临时导入目录与定时导入

| 项 | 内容 |
| --- | --- |
| 指定方式 | 首次运行引导页，与相册目录一起用目录浏览器选择 |
| 扫描频率 | 固定间隔，每小时一次 |
| 扫描范围 | 递归扫描所有子目录 |
| 导入文件类型 | 扩展名不区分大小写，其他文件忽略、留在原处：<br>图片：`jpg jpeg heic heif png gif webp tif tiff`<br>RAW：`cr2 cr3 nef arw dng raf orf rw2`<br>视频：`mp4 mov` |
| 导入方式 | 移动：导入成功后从临时导入目录删除 |
| 文件权限 | 移动后的文件和新建的日期目录，继承相册共享文件夹的属主和权限 |
| 空目录处理 | 导入后变空的子目录自动删除；只剩 `.DS_Store`、`._*`、`Thumbs.db` 这类系统垃圾文件也算空，连同它们一起删除 |
| 跳过规则 | 跳过所有以 `@` 或 `.` 开头的目录和文件（如 `@Recycle`、`@__thumb`、`.DS_Store`、`._*`），导入和索引都适用 |
| 写入检测 | 扫描前记录导入目录内所有文件的大小和修改时间，30 秒后再记一次；有任何变化（含新增文件）就认为有写入任务，跳过本次整个扫描，并在当天日志写一行“检测到写入，跳过本次扫描”（`logs/`、`duplicates/` 不参与检测） |
| 扫描并发 | 同一时间只允许一个扫描在运行；到点时上次扫描还没完成，就跳过本次，并在日志写一行“上次扫描未完成，跳过” |

### 3.1 目标位置

按拍摄日期放进相册目录下的子目录：`YYYY/YYYY-MM/YYYY-MM-DD`，月和日不足两位时前面补 0（例：`2026/2026-11/2026-11-07/`）。

拍摄日期从哪里取：

| 文件类型 | 优先 | 取不到时 |
| --- | --- | --- |
| 图片 / RAW | EXIF 拍摄时间 | 文件修改时间 |
| 视频 | 视频元数据里的拍摄/创建时间 | 文件修改时间 |

时区：统一按 NAS 系统时区换算日期。视频的 UTC 时间先转成 NAS 时区；带时区偏移的 EXIF 也换算；不带时区的 EXIF 直接当作本地时间。

### 3.2 冲突与重复

“内容相同”一律以 MD5 一致为准。

| 情况 | 比较范围 | 处理 |
| --- | --- | --- |
| 同名，内容相同 | 目标日期目录 | 不导入，移到重复文件目录 |
| 同名，内容不同 | 目标日期目录 | 自动重命名后导入：在扩展名前加 `_N`，N 从 1 开始递增，取第一个不存在的编号（`IMG_0001_1.jpg` → `IMG_0001_2.jpg` → …） |
| 不同名，内容相同 | 整个相册目录（含所有子目录） | 不导入，移到重复文件目录 |
| 同一次扫描中，导入目录内有多个文件内容相同 | 本次扫描的文件 | 第一个正常导入，其余视为重复，移到重复文件目录 |

重复文件目录：`临时导入目录/duplicates/YYYYMMDD_HHMMSS/`

- 时间取本次扫描的开始时间，每次扫描新建一个
- 文件保留原来在导入目录里的相对路径
- 扫描时跳过整个 `duplicates/` 目录

### 3.3 导入日志

| 项 | 内容 |
| --- | --- |
| 写入时机 | 每次扫描导入完成后 |
| 文件位置 | 临时导入目录下的固定子目录 `logs/`（扫描时跳过该目录） |
| 文件划分 | 每天一个文件，文件名 `YYYYMMDD.log`（按扫描开始日期归属） |
| 记录范围 | §3.2 的全部 4 种冲突情况 |

记录格式：

- 每次扫描写一行：开始时间、完成时间
- 每个冲突文件写一行：`冲突类型 | 导入目录中的源路径 | 相册中与之冲突的文件路径`
  - “同名内容不同”的情况，第三列写重命名后的新路径
  - “同一次扫描中重复”的情况，第三列写本次第一个导入的文件在相册中的路径

- 导入失败的文件写一行：`失败 | 导入目录中的源路径 | 原因`

### 3.3.1 导入失败处理

- 单个文件失败（读写错误、没有权限等）：该文件留在原处不动，下次扫描再试；写一行失败日志；其他文件继续处理
- 磁盘空间不足：中止本次扫描，并写日志

### 3.4 相册 MD5 索引

| 项 | 内容 |
| --- | --- |
| 索引范围 | 相册目录下支持导入的文件类型（图片 / RAW / 视频），跳过系统和隐藏目录 |
| 首次建立 | 首次运行时全量计算并保存；在后台进行，引导页完成后可以关闭页面；中断（如重启）后接着继续 |
| 与定时扫描的关系 | 首次索引完成前，不启动定时扫描 |
| 增量更新 | 每次扫描前，按文件路径 + 大小 + 修改时间增量更新，能发现手动增删改的文件 |
