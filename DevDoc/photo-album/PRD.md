## 1. 运行平台与交付形式

| 项 | 内容 |
| --- | --- |
| 目标硬件 | QNAP TS-873A（AMD Ryzen V1500B，x86_64） |
| 操作系统 | QTS 5.x |
| 交付形式 | 原生 QPKG 安装包，通过 App Center 安装/管理 |
| 定位 | 独立软件 |

## 2. 首次运行：指定相册目录

| 项 | 内容 |
| --- | --- |
| 触发时机 | 第一次运行（打开软件 Web 界面时弹出引导页） |
| 指定方式 | 在引导页里用目录浏览器选择 NAS 上的共享文件夹 |
| 目录数量 | 仅一个，包含其所有子目录 |
| 后续修改 | 暂不定义 |
| 同时指定 | 临时导入目录（见第 3 节），在同一引导页用同样方式选择 |

## 3. 临时导入目录与定时导入

| 项 | 内容 |
| --- | --- |
| 指定方式 | 首次运行引导页，与相册目录一起用目录浏览器选择 |
| 扫描频率 | 固定间隔，每小时一次 |
| 扫描范围 | 递归扫描所有子目录 |
| 导入文件类型 | 图片、相机 RAW、视频（MP4/MOV）；其他文件忽略，留在原处 |
| 导入方式 | 移动：导入成功后从临时导入目录删除 |
| 空目录处理 | 导入后变空的子目录自动删除 |

### 3.1 目标位置

按拍摄日期放进相册目录下的子目录：`YYYY/YYYY-MM/YYYY-MM-DD`，月和日不足两位时前面补 0（例：`2026/2026-11/2026-11-07/`）。

拍摄日期从哪里取：

| 文件类型 | 优先 | 取不到时 |
| --- | --- | --- |
| 图片 / RAW | EXIF 拍摄时间 | 文件修改时间 |
| 视频 | 视频元数据里的拍摄/创建时间 | 文件修改时间 |

### 3.2 冲突与重复

“内容相同”一律以 MD5 一致为准。

| 情况 | 比较范围 | 处理 |
| --- | --- | --- |
| 同名，内容相同 | 目标日期目录 | 不导入，留在临时导入目录 |
| 同名，内容不同 | 目标日期目录 | 自动重命名后导入（如 `IMG_0001_1.jpg`） |
| 不同名，内容相同 | 整个相册目录（含所有子目录） | 不导入，留在临时导入目录 |
| 同一次扫描中，导入目录内有多个文件内容相同 | 本次扫描的文件 | 第一个正常导入，其余视为重复，留在临时导入目录 |

### 3.3 导入日志

| 项 | 内容 |
| --- | --- |
| 写入时机 | 每次扫描导入完成后 |
| 文件位置 | 临时导入目录下的固定子目录 `logs/`（扫描时跳过该目录） |
| 文件划分 | 每天一个文件，文件名 `YYYYMMDD.log`（按扫描开始日期归属） |
| 记录范围 | §3.2 的全部 4 种冲突情况 |

记录格式：

- 每次扫描写一行：开始时间、完成时间
- 每个冲突文件写一行：`冲突类型 | 导入目录中的源路径 | 相册中与之冲突的文件路径`
  - “同名内容不同”的情况，第三列写重命名后的新路径
  - “同一次扫描中重复”的情况，第三列写本次第一个导入的文件在相册中的路径
