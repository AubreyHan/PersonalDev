# 产品需求文档 (PRD) - english-word (智能英语单词学习与复习系统)

## 1. 背景与目标 (Background & Goals)

### 1.1 背景
市面上大多数背单词软件要么采用“纯刷闪卡（点认识/不认识）”的虚假记忆模式（导致用户看词眼熟、动笔不会拼、开口不会读、放到句子里不会变形），要么内置固定词书，无法让用户随时随地录入并深度精学自己在日常阅读、工作或辅导中遇到的生词与词组。

### 1.2 核心目标
打造一款**跨平台自适应、支持离线使用的 PWA 多租户英语单词与词组精学软件**：
- **扁平多租户架构**：管理员（`admin`）统筹管理用户账号；取消复杂的师生层级身份，所有常规用户统一为自主学习者（`user`），每个人均可自主录入与管理个人专属词库，词库与学习复习进度完全独立私有、互不干扰。
- **极简智能的个人录词与智能补全**：用户只需输入英文单词或词组，系统通过权威词典 + Cloudflare Workers AI 自动补全音标、音节切分、地道中文释义、全套词形变化、同音词表、真人发音及带挖空标记的双语例句；支持用户随时编辑微调。
- **听说读写四维一体的「学习」闭环**：摒弃走马观花式翻卡，每个单词必须依次通过「盲打听写（含词形变化）3 遍 -> 中文释义四选一 -> 真人跟读准确 3 次 -> 例句语境变形填空」四步闯关，全方位建立肌肉记忆。
- **严密防作弊的艾宾浩斯「复习」引擎**：按艾宾浩斯遗忘曲线（+1、2、4、7、15、30 天）自动筛选每日待复习词，**不提前暴露复习列表**，随机顺序 100% 覆盖抽考；未复习自动顺延；复习时支持 1 次快速通关，一旦出错或看提示则当场触发 3 遍强化 + 艾宾浩斯阶段重置回第 1 阶段 + 当日队尾回炉重考。

## 2. 用户角色与权限矩阵 (User Roles & Permissions)

系统包含 2 类角色，均通过「用户名（`username`）+ 密码」登录，支持随时自愿修改个人密码：

| 角色标识 | 默认/初始密码 | 核心职责与权限边界 |
| :--- | :--- | :--- |
| **`admin` (系统管理员)** | `P@ss=w0rd` | 1. 系统内置唯一超级管理员账号 `admin`，可自行修改密码。<br/>2. **用户账号统筹管理**：添加新用户账号（填写唯一用户名 + 可选显示姓名，默认密码 `passw0rd`）。<br/>3. **重置密码与删除用户**：一键将任意用户的密码重置为 `passw0rd`；彻底删除用户账号时级联清理该用户的所有词库与学习记录。<br/>4. **系统总览看板**：查看全站用户列表及其词条总数、掌握进度和最近活跃时间。 |
| **`user` (学习者/常规用户)** | `passw0rd` | 1. **个人专属词库管理**：支持单条智能录入单词/词组（自动补全音标、音节切分、中文释义、词形变化、同音词、双语例句与发音）；支持检索、编辑、删除与去重提示；个人词库完全独立私有。<br/>2. **「学习」模块**：通过步骤 1（认知展示页）+ 步骤 2（听写、翻译、跟读、例句填空四步闯关）完成生词初学，支持子步骤断点续学。<br/>3. **「复习」模块**：按艾宾浩斯记忆曲线对已学单词进行每日随机盲测复习，及对「已彻底掌握」词库进行自由随机抽查。<br/>4. **个人学情统计**：查看个人词条总数、今日学习/复习进度、艾宾浩斯各阶段分布及高频错词榜单。 |

## 3. 功能需求详细规格 (Functional Requirements)

### 3.1 Admin 端：用户账号管理 (FR-1)
- **FR-1.1 管理员初始化与认证**：
  - 系统首次部署自动初始化 `username = "admin"`，初始密码 `P@ss=w0rd`。
  - 所有用户登录后均可在右上角个人中心随时修改自己的密码。
- **FR-1.2 用户创建与列表总览**：
  - Admin 可新建用户：输入 `username`（必填，字母/数字/下划线，全局唯一）与 `displayName`（可选，默认同 `username`），初始密码设为 `passw0rd`。
  - Admin 可查看系统所有用户的学情概览（词条数、已学数、已掌握数、最近活跃时间）。
- **FR-1.3 用户密码重置与账号删除**：
  - Admin 可一键将任意用户密码重置为 `passw0rd`。
  - Admin 删除用户时：弹出确认框，确认后物理级联清理该用户账号、个人词库及全部学习/复习进度。

---

### 3.2 User 端：个人词库管理与智能录词 (FR-2)
- **FR-2.1 单条智能录入与自动补全**：
  - 用户输入英文单词（如 `information`, `fear`）或词组（如 `be related to`, `a sense of humour`），点击「智能补全」：
  - 系统通过 **权威词典 API + Cloudflare Workers AI** 自动填充以下结构化字段（所有字段均支持用户手动微调）：
    1. **标准词条 (`text`)** 与 **音节切分展示 (`syllables`)**：如 `in·for·ma·tion`（单音节词或词组保持原样）。
    2. **音标 (`phoneticUs` / `phoneticUk`)** 与 **真人发音音频 (`audioUsUrl` / `audioUkUrl`)**：支持词典原声及针对词组的神经网络高拟真 TTS 合成音频。
    3. **词性与中文释义列表 (`meanings`)**：支持单词词性拆分及短语核心释义提取（如 `[{ pos: "phr.", zh: "与……有关" }]`），杜绝英文释义或占位符。
    4. **词形变化 (`inflections`)**：名词复数、动词时态（含 `be` 动词不规则变化）、分词、比较级等；词组针对核心动词变化。
    5. **同音异义词列表 (`homophones`)**：用于复习盲听写时的歧义保护。
    6. **带精准挖空标记的双语例句 (`examples`)**：真实双语中英例句，精准匹配句中目标词或变形文本。
    7. **可选标签 (`tags`)**：便于用户按主题或场景分类标记。
- **FR-2.2 词库检索、去重与维护**：
  - 若用户再次添加已存在于自己词库中的单词/词组，系统弹出重复提示并定位到已有词条，防止重复录入。
  - 支持按关键词（英文/中文）、添加日期、标签筛选，支持随时编辑词条内容或删除词条。

---

### 3.3 User 端：听说读写「学习」四步递进式闯关引擎 (FR-3)
- **FR-3.1 词库学习与优先复习引导**：
  - 进入「今日学习」时，若当天有到期的「待复习」单词未完成，系统温和提醒建议优先复习，防止多日欠账。
- **FR-3.2 步骤 1：单词认知展示页 (Step 1: Cognitive Preview)**：
  - 完整展示：英文单词/词组、音节拆解、英美音标、词性与中文释义、全套词形变化标签、双语例句（高亮目标词）。
  - 进入页面时**自动播放真人发音**，支持反复点击发音。
- **FR-3.3 步骤 2：四步递进闯关（每步解锁下一步，支持断点保存）**：
  - **2.1 单词盲打听写 (Blind Dictation - 3 Reps)**：
    - 全盲界面：隐藏英文原词与中文，仅听真人发音，提供下划线字母格。
    - 原词盲打 3 遍；满 3 遍后渐进弹出词形变化各盲打 3 遍（拼写相同变形自动合并为 1 组）。
    - 看提示惩罚：点击提示后，当前拼写项已打遍数重置为 `0 / 3`。
  - **2.2 单词翻译四选一 (Meaning Selection)**：
    - 展示英文单词/词组与音标，下方提供 4 个中文释义选项（1 正确 + 3 混淆）。选错打乱重选。
  - **2.3 跟读发音评测 (Pronunciation Evaluation - Cumulative 3 Passes)**：
    - Workers AI (Whisper) + 本地离线语音双模评测，**累计 3 次准确读音**；支持回放录音与标准音对比；支持静音环境兜底模式。
  - **2.4 语境例句变形填空 (Contextual Cloze Fill-in)**：
    - 结合中文翻译与句意语境，在挖空字母格中手动拼写填入正确的单词形态。
- **FR-3.4 完成学习与入池**：
  - 2.4 完成后进入艾宾浩斯复习池（阶段 1：次日待复习）。
  - 子步骤级断点续学：退出后再次进入自动恢复未完成子步骤。

---

### 3.4 User 端：艾宾浩斯「复习」引擎 (FR-4)
- **FR-4.1 艾宾浩斯 6 阶段周期与未复习自动顺延**：
  - 6 个标准复习阶段：`Stage 1 (+1天)`、`Stage 2 (+2天)`、`Stage 3 (+4天)`、`Stage 4 (+7天)`、`Stage 5 (+15天)`、`Stage 6 (+30天)`。
  - 未复习自动顺延：若当天未复习，到期词自动顺延至今天，后续复习节点基于实际复习完成日动态推算，无挤压重叠。
- **FR-4.2 盲测防剧透与随机全覆盖**：
  - 严禁提前暴露待复习单词列表；进入后对今日待复习词进行随机洗牌（Shuffle），逐一抽考并 100% 覆盖。
- **FR-4.3 智能减负与错词回炉惩罚**：
  - 跳过步骤 1，直接进入四步考核（2.1 听写 -> 2.2 翻译 -> 2.3 跟读 -> 2.4 例句填空）。
  - 同音词保护：盲打提示词性，合法同音词友好提示且不触发惩罚。
  - 正常 1 次快速通关：复习模式下听写与跟读默认各 1 次通关。
  - 出错/看提示三重惩罚：
    1. 当场强化：切换为 3 遍盲打与跟读；
    2. 周期重置：重置回 Stage 1（次日必须复习），累加错题次数；
    3. 当日队尾回炉：重新插入今日复习队列末尾，今日必须再次零错误通过。
- **FR-4.4 修满毕业与已掌握词库抽查**：
  - Stage 6 通关后升级为「已彻底掌握」；提供随机抽查入口，抽查出错自动复活拉回 Stage 1。

## 4. 非功能性需求与离线/多端规格 (Non-Functional Requirements)

- **PWA 跨平台响应式体验**：适配桌面端物理键盘盲打（快捷键、自动聚焦）与移动端触屏虚拟键盘。
- **离线优先 (Local-First)**：本地 IndexedDB 存储词库与进度；真人发音 MP3 预缓存；断网照常学练复习；联网后通过增量同步协议与云端 D1 双向同步。

## 5. 验收标准 (Acceptance Criteria)

- [ ] **AC-1 (Admin 用户管理)**：使用 `admin` / `P@ss=w0rd` 登录，验证创建新用户、一键重置密码及删除用户功能正常。
- [ ] **AC-2 (用户自主智能录词)**：使用常规用户登录，在词库页面添加单词 `run` 或词组 `be related to`，验证自动补全真实中文释义、音标、变形及双语例句，验证重复录入去重拦截。
- [ ] **AC-3 (学习四步闯关)**：用户进入「今日学习」，验证认知展示 -> 2.1 盲打听写（原词+变形各3遍） -> 2.2 四选一 -> 2.3 跟读3次 -> 2.4 例句填空；验证断点恢复。
- [ ] **AC-4 (艾宾浩斯复习)**：用户进入「今日复习」，验证不剧透列表、随机抽查、1遍通关、错题3重强化惩罚与顺延逻辑。
- [ ] **AC-5 (离线与数据隔离)**：在断网模式下验证学练顺畅；验证不同用户之间词库与复习进度 100% 隔离。
