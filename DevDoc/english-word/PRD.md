# 产品需求文档 (PRD) - english-word (智能英语单词学习与复习系统)

## 1. 背景与目标 (Background & Goals)

### 1.1 背景
市面上大多数背单词软件要么采用“纯刷闪卡（点认识/不认识）”的虚假记忆模式（导致学生看词眼熟、动笔不会拼、开口不会读、放到句子里不会变形），要么内置庞大冗余的固定词书，难以贴合教师日常教学、课外阅读或针对性辅导的生词与词组积累需求。

### 1.2 核心目标
打造一款**跨平台自适应、支持离线使用的 PWA 多租户英语单词与词组精学软件**，解决以下核心诉求：
- **清晰的师生多租户组织**：由管理员（`admin`）统筹创建教师，并在教师名下创建或关联现有学生（支持多对多师生归属）。
- **极简智能的教师备词与学情追踪**：教师只需输入英文单词或词组，系统自动补全音标、音节切分、中文释义、全套词形变化、同音词表、真人发音及带挖空标记的双语例句；并能实时洞察每位学生的学习进度、今日复习完成度与高频顽固错词。
- **听说读写四维一体的「学习」闭环**：摒弃走马观花式翻卡，每个单词必须依次通过「盲打听写（含词形变化）3 遍 -> 中文释义四选一 -> 真人跟读准确 3 次 -> 例句语境变形填空」四步闯关，全方位建立肌肉记忆。
- **严密防作弊的艾宾浩斯「复习」引擎**：按艾宾浩斯遗忘曲线（+1、2、4、7、15、30 天）自动筛选每日待复习词，**不提前暴露复习列表**，随机顺序 100% 覆盖抽考；未复习自动顺延；复习时支持 1 次快速通关，一旦出错或看提示则当场触发 3 遍强化 + 艾宾浩斯阶段重置回第 1 阶段 + 当日队尾回炉重考。

## 2. 用户角色与权限矩阵 (User Roles & Permissions)

系统包含 3 类角色，均通过「用户名（`username`）+ 密码」登录，支持随时自愿修改个人密码（不强制首次改密拦截）：

| 角色标识 | 默认/初始密码 | 核心职责与权限边界 |
| :--- | :--- | :--- |
| **`admin` (系统管理员)** | `P@ss=w0rd` | 1. 系统内置唯一超级管理员账号 `admin`，可自行修改密码。<br/>2. **创建与管理教师**：添加教师账号（填写唯一用户名 + 可选显示姓名，默认密码 `passw0rd`），重置教师密码，删除教师。<br/>3. **在教师名下管理学生**：必须先进入某位教师的管理视图，在该教师名下**直接新建学生账号**（默认密码 `passw0rd` 并自动绑定该教师）或**从系统已有学生中选择并绑定**（支持 1 名学生关联多名教师的 N:M 关系）。<br/>4. **解绑与删除保护**：支持将学生“移出当前教师名下（仅解除绑定）”或“彻底删除学生账号”；删除教师时对名下词库与独占学生执行清理/转移确认；支持重置任意学生密码为 `passw0rd`。 |
| **`teacher` (教师)** | `passw0rd` | 1. **单词/词组单条智能录入与管理**：输入英文单词或词组，触发词典 + AI 智能补全（音标、音节切分、中文释义、词形变化、同音词、双语例句及发音），确认或微调后保存至本教师统一词库（默认对本教师名下全体学生生效）。<br/>2. **词库维护**：支持关键词搜索、按添加日期/标签筛选、编辑、删除及重复录入自动去重提示。<br/>3. **学生学情监控**：查看名下每位学生的学习进度概览（已学/未学/已彻底掌握数、最近活跃时间）、今日待复习完成进度，以及该学生的「高频错词/多次降级顽固词榜单」。 |
| **`student` (学生)** | `passw0rd` | 1. **多教师词库聚合与互通**：默认聚合所关联的全部教师生词（支持按教师、按学习状态筛选）；不同教师录入同一单词时，学生的学习与艾宾浩斯复习进度**全局共享互通**（免重复学习，例句合并展示）。<br/>2. **「学习」模块**：通过步骤 1（认知展示页）+ 步骤 2（听写、翻译、跟读、例句填空四步闯关）完成生词初学。<br/>3. **「复习」模块**：按艾宾浩斯记忆曲线对已学单词进行每日随机盲测复习，及对「已彻底掌握」词库进行自由随机抽查。 |

## 3. 功能需求详细规格 (Functional Requirements)

### 3.1 Admin 端：多租户与师生层级管理 (FR-1)
- **FR-1.1 管理员初始化与认证**：
  - 系统首次部署自动初始化 `username = "admin"`，初始密码 `P@ss=w0rd`。
  - 所有角色（`admin` / `teacher` / `student`）登录后均可在右上角个人中心随时修改自己的密码。
- **FR-1.2 教师管理**：
  - Admin 可新建教师：输入 `username`（必填，字母/数字/下划线，全局唯一）与 `displayName`（可选，默认同 `username`），密码自动设为 `passw0rd`。
  - Admin 可一键将任意教师密码重置为 `passw0rd`。
  - Admin 删除教师时：弹出确认框提示该教师名下的词条数量及关联学生情况；若存在**仅归属该教师一人**的独占学生，提示先将其关联至其他教师或确认连带清理。
- **FR-1.3 教师名下的学生创建与多对多关联**：
  - Admin 不可脱离教师直接创建游离学生，**必须先选择某一位已创建的教师**，在其详情/管理抽屉中执行两类操作：
    1. **新建学生并绑定**：输入新学生的 `username` 与 `displayName`，密码默认设为 `passw0rd`，创建后自动建立与当前教师的绑定关系。
    2. **选择现有学生并绑定**：从系统中已创建（归属在其他教师名下）的学生列表中勾选 1 名或多名学生，一键绑定到当前教师名下。
- **FR-1.4 学生移出解绑与彻底删除**：
  - **移出该教师名下**：当该学生同时关联了 $\ge 2$ 名教师时，可仅解除其与当前教师的绑定（不影响其账号及在其他教师下的学习数据）；若该学生当前仅关联这 1 名教师，点击移出时提示“该学生无其他归属教师，继续操作将彻底删除该学生账号”。
  - **彻底删除学生**：物理清理该学生账号、所有师生绑定关系及其个人学习/复习记录。
  - **重置学生密码**：一键重置为默认密码 `passw0rd`。

### 3.2 教师端：智能生词管理与学情看板 (FR-2)
- **FR-2.1 单条智能录入与自动补全**：
  - 教师输入英文单词（如 `information`, `write`, `run`）或词组（如 `look forward to`, `take care of`），点击「智能补全」：
  - 系统通过 **权威词典 API + Cloudflare Workers AI** 自动填充以下结构化字段（所有字段均支持教师手动编辑微调）：
    1. **标准词条 (`text`)** 与 **音节切分展示 (`syllables`)**：如 `in·for·ma·tion`（单音节词或词组则保持原样）。
    2. **音标 (`phoneticUs` / `phoneticUk`)** 与 **真人发音音频 (`audioUsUrl` / `audioUkUrl`)**：支持词典原声及针对词组的神经网络高拟真 TTS 合成音频。
    3. **词性与中文释义列表 (`meanings`)**：如 `[{ pos: "n.", zh: "信息；资料" }]`。
    4. **词形变化 (`inflections`)**：如名词复数 (`plural`)、动词第三人称单数 (`thirdPerson`)、现在分词 (`presentParticiple`)、过去式 (`pastTense`)、过去分词 (`pastParticiple`)、形容词/副词比较级 (`comparative`) 与最高级 (`superlative`)；词组则针对核心动词变形（如 `looked forward to`）。
    5. **同音异义词列表 (`homophones`)**：如 `write` 自动关联 `["right", "rite"]`，用于复习盲听写时的歧义保护。
    6. **带精准挖空标记的双语例句 (`examples`)**：至少 1~2 条例句，包含英文原句、中文翻译、以及句中目标词（或其词形变化形态）的精准匹配文本（如例句 `"He wrote a letter yesterday."`，目标填空词为 `"wrote"`）。
    7. **可选标签 (`tags`)**：便于教师按单元或主题分类标记。
- **FR-2.2 词库检索、去重与维护**：
  - 若当前教师再次添加已存在于自己词库中的单词/词组，系统立即弹出重复提示并定位到已有词条，防止重复录入。
  - 支持按关键词（英文/中文）、添加日期、自定义标签筛选，支持随时编辑词条内容或删除词条。
- **FR-2.3 名下学生学情与薄弱错词看板**：
  - 展示本教师名下所有关联学生的学情汇总表：学生姓名/账号、词库总词数、未学数、学习中（已学待复习）数、已彻底掌握数、今日待复习完成度（如 `12 / 15`）、最近学习时间。
  - 点击任意学生可展开详情抽屉，查看该学生的**「高频错词 / 多次重置回第 1 阶段的顽固薄弱词榜单」**（显示错题次数、卡壳环节如听写拼错/发音不准/例句填错），辅助教师精准教学。

### 3.3 学生端模块一：「学习」四步递进式闯关引擎 (FR-3)
- **FR-3.1 词库聚合与优先复习引导**：
  - 学生登录后，默认聚合其关联的所有教师的生词列表；顶部支持按「全部教师 / 指定教师」及「学习状态（未学 / 已学复习中 / 已彻底掌握）」筛选查阅。
  - **防积压引导**：若学生当天有到期的「待复习」单词未完成，系统在导航栏及开始学习前弹出温和引导提示：“您今日还有 N 个单词待复习，建议先完成今日复习再学新词”（学生可选择立即去复习或继续学新词）。
- **FR-3.2 步骤 1：单词认知展示页 (Step 1: Cognitive Preview)**：
  - 完整展示：英文单词/词组、**分音节拆解 (`in·for·ma·tion`)**、英/美音标、词性与中文释义、全套词形变化标签、双语例句（高亮句中目标词或变形）。
  - 进入页面时**自动播放真人发音**，并在单词旁与每条例句旁提供发音按钮，支持学生反复点击聆听。
  - 页面底部提供醒目的「开始学习」主按钮。
- **FR-3.3 步骤 2：四步递进闯关（每完成一步才可解锁下一步，支持子步骤断点保存）**：
  - **2.1 单词盲打听写 (Blind Dictation - 3 Reps)**：
    - **全盲界面**：隐藏英文原词与中文释义，仅播放真人发音（并提供重听按钮）及展示**下划线字母格（`_ _ _ _ _`）**提示单词长度（词组自动留出空格或连字符）。
    - **原词盲打 3 遍**：学生需连续准确盲打原词 **3 遍**；每敲入一个字母提供清脆按键音与实时对错色彩反馈。
    - **词形变化渐进式盲打（各 3 遍 + 相同拼写自动合并）**：原词满 3 遍后，若该词存在词形变化，系统**依次渐进式弹出**变化形式要求（如“请拼写：过去式 / 过去分词”）。若过去式与过去分词拼写完全相同（如 `played`），**自动合并为 1 组**，每组同样需盲打 **3 遍**。
    - **兜底提示与重置**：若学生遗忘拼写，可点击「看一眼提示」或「退回步骤 1 重看」，但触发后**当前正在拼写的项（原词或当前变形）的已打遍数重置为 `0 / 3`**，必须重新无提示盲打满 3 遍方可过关。
  - **2.2 单词翻译四选一 (Meaning Selection)**：
    - 展示英文单词/词组与音标（自动朗读），下方展示 **4 个中文释义选项**（1 个正确释义 + 3 个从词库或内置混淆词池随机抽取的干扰项）。
    - 若选错：给出错误抖动反馈，自动重新打乱 4 个选项顺序，学生需重新选出正确答案方可进入 2.3。
  - **2.3 跟读发音评测 (Pronunciation Evaluation - Cumulative 3 Passes)**：
    - 展示单词/词组、音节切分与音标，提供标准音示范按钮与录音跟读按钮。
    - 学生跟读后，系统通过 **云端 Whisper (Workers AI) + 本地离线语音双模引擎**评测发音准确度（综合识别文本音素相似度与置信度，得分 $\ge 80$ 分判为准确）。
    - **累计 3 次达标**：每读准 1 次点亮 1 颗星（共 3 颗）；若某次读音不准，**不清零已点亮星数**，提示重听标准音并支持点击**「回放我的录音 vs 标准音对比」**进行纠音；满 3 次准确后解锁下一步（不自动跳词，先进入 2.4）。
    - **静音环境兜底开关**：提供「当前不便开口（静音模式）」临时切换，开启后用“听音辨音标/拼读”替代麦克风录音。
  - **2.4 语境例句变形填空 (Contextual Cloze Fill-in)**：
    - 展示英文例句（将句中的目标词或其变形形态替换为下划线字母格）及完整中文翻译。
    - 学生需结合语境与时态提示，通过键盘手动拼写填入正确的单词形态（如 `went`、`books`、`looked forward to`）。若有多条例句则依次完成。
    - 同样支持“看一眼提示（重置当前句输入）”。
- **FR-3.4 完成学习与入池**：
  - 当 2.4 全部完成后，庆祝动效提示当前单词学习完成，正式将该单词状态标记为**「已学（进入艾宾浩斯复习池，阶段 1：次日待复习）」**，并自动进入下一个未学单词的步骤 1。
  - **子步骤断点续学**：若学生在 2.1~2.4 任意小步中途退出或刷新页面，本地 IndexedDB 实时保存当前单词及子步骤状态（如 `currentSubStep: '2.3', readPassCount: 2`），再次进入时直接从断点处继续。

### 3.4 学生端模块二：艾宾浩斯「复习」引擎 (FR-4)
- **FR-4.1 艾宾浩斯 6 阶段周期与未复习自动顺延**：
  - 所有完成「学习」的单词自动进入复习词库，设定 **6 个标准艾宾浩斯复习阶段**，间隔周期分别为（相对于上一阶段实际完成日期）：
    - **Stage 1**：`+1 天`
    - **Stage 2**：`+2 天`
    - **Stage 3**：`+4 天`
    - **Stage 4**：`+7 天`
    - **Stage 5**：`+15 天`
    - **Stage 6**：`+30 天`
  - **未复习自动顺延**：系统以自然日为单位计算今日到期单词（`nextReviewDate <= today`）。若学生某天或连续几天未复习，所有到期未复习单词自动顺延至今天作为待复习词；且由于下一阶段的 `nextReviewDate` 均基于**本次复习实际完成日 (`actualReviewedDate + intervalDays`)** 动态推算，后续所有复习节点自然同步顺延，绝不发生同一单词多阶段重叠挤压。
- **FR-4.2 盲测防剧透与随机全覆盖**：
  - 学生进入「复习」页面时，**严禁提前展示当天的待复习单词列表**（防止考前突击浏览产生瞬时假性记忆），界面仅展示今日待复习总数、今日已完成数、学习连续打卡天数及「开始复习 / 继续复习」按钮。
  - 点击开始后，系统将今日所有待复习单词进行 **Fisher-Yates 随机洗牌（Shuffle）**，逐个抽考，确保当天所有到期单词 100% 覆盖。
- **FR-4.3 无展示页直接四步考核与「智能减负 + 错词强化」**：
  - 抽考每个单词时，**跳过步骤 1（认知展示页）**，直接依次考核：`2.1 单词听写` -> `2.2 单词翻译` -> `2.3 跟读评测` -> `2.4 例句填空`。
  - **同音词盲听歧义保护**：在复习的第 1 步（2.1 盲听写）时，界面展示该词的**词性提示（如 `v.` / `n.`）**；若学生拼写出的单词恰好是合法的同音异义词（如考 `right` 却输入了 `write`），系统提示“这是同音词，请拼写另一个词性为 `adj.` 的词”，**不计入错题且不触发惩罚**。
  - **原词通过后渐进弹出变形**：在 2.1 中先仅展示原词输入框，原词拼对后再依次弹出各词形变化输入框。
  - **正常 1 次快速通关**：在复习模式下，原词盲打、各词形变化盲打、以及 2.3 跟读评测默认均只需 **1 次准确**即可过关，大幅提升日常复习流畅度。
  - **出错/看提示的三重强化惩罚**：若学生在当前单词的 `2.1`、`2.2`、`2.4` 任一环节答错或主动点击了「看一眼提示」：
    1. **当场强化**：立即弹出单词详情卡片供学生重温，且当前单词的听写（原词及变形）与跟读自动切换为初学标准（**需连续盲打 3 遍 / 跟读 3 次**）才可走完当前词；
    2. **艾宾浩斯周期重置**：该单词的艾宾浩斯阶段**重置回 Stage 1（间隔 +1 天，即次日必须再次复习）**，并累加该词的 `errorCount`（供教师端薄弱错词榜统计）；
    3. **当日队尾回炉重考（Intra-day Re-queue）**：将该单词标记为“今日需回炉”，自动重新插入到今日待复习队列的末尾（若队列剩余词数较多则随机混入最后几个词中），今天结束前必须再完成一次**无提示、零错误的一遍过关**，才算真正完成今日对该词的复习！
- **FR-4.4 修满毕业与「已彻底掌握」词库抽查复活**：
  - 当某个单词在 Stage 6（+30 天节点）**一次无错顺利通关**后，该单词正式升级为**「已彻底掌握 (Mastered)」**，不再进入日常自动复习队列。
  - 在「复习」页底部提供「已掌握词库随机抽查（共 X 词）」入口：学生可随时抽取 10/20 个已掌握单词进行四步盲测；若抽查中某词全部一次通过则维持「已彻底掌握」，若抽查中途出错或看提示，则自动将该词**复活并拉回艾宾浩斯复习池（重置为 Stage 1，次日开始重新复习）**。

## 4. 非功能性需求与离线/多端规格 (Non-Functional Requirements)

- **PWA 跨平台响应式体验**：
  - 提供标准 `manifest.webmanifest` 与 Service Worker，支持在桌面端 Chrome/Edge/Safari 及移动端 iOS（添加到主屏幕）/Android 安装为独立窗口应用。
  - 桌面端优化物理键盘盲打体验（全局自动聚焦输入框、`Enter` 键提交/下一步、快捷键重播发音）；移动端/平板优化虚拟键盘弹出时的视口布局与触控热区。
- **离线优先 (Local-First) 与音频预缓存**：
  - 所有词库、学习子步骤断点、艾宾浩斯复习计划均优先读写本地 IndexedDB（基于 `Dexie.js`）。
  - 联网状态下自动将学生关联词库的真人发音 MP3 预缓存至本地 `Cache Storage` / `IndexedDB`；断网状态下应用 100% 可打开、可学新词、可做今日复习、可播放已缓存真人发音（未缓存音频自动降级 Web Speech TTS）。
  - 每次操作产生本地变更日志（Outbox / Sync Queue），网络恢复或切换设备登录时，自动与 Cloudflare Workers + D1 数据库执行增量双向同步。

## 5. 验收标准 (Acceptance Criteria)

- [ ] **AC-1 (Admin 师生层级)**：使用 `admin` / `P@ss=w0rd` 登录，验证必须先创建教师，再在教师详情下创建新学生或绑定已有学生；验证移出解绑与彻底删除逻辑符合多对多归属保护规则。
- [ ] **AC-2 (教师智能录入)**：使用教师账号登录，输入单词 `run` 或词组 `look forward to`，验证自动补全音标、音节、中文释义、词形变化、同音词及带挖空的双语例句，且同教师重复录入同名单词时触发去重提示。
- [ ] **AC-3 (学习四步闭环)**：使用学生账号进入「学习」，验证步骤 1 展示及自动发音 -> 2.1 全盲听写原词 3 遍及合并后变形各 3 遍（验证看提示后当前项重置为 0/3） -> 2.2 四选一（选错打乱重选） -> 2.3 跟读累计 3 次准确（验证录音回放对比与静音开关） -> 2.4 例句变形填空；验证中途刷新页面可精准恢复到当前子步骤。
- [ ] **AC-4 (艾宾浩斯复习与错词回炉)**：进入「复习」，验证不显示当日待复习单词列表；验证默认听写/跟读 1 次通关并晋级下一阶段；验证人为拼错或点提示后触发“当场 3 遍强化 + 阶段重置为 Stage 1 + 追加至今日队列末尾回炉重考”；验证修改系统日期模拟跨天未复习时，到期词及后续周期自动顺延 1 天。
- [ ] **AC-5 (离线可用与多端同步)**：在 Chrome DevTools 开启 `Offline` 断网模式，验证学生端仍可正常加载词库、播放预缓存真人发音并完成学习与复习；恢复 `Online` 后验证进度自动同步至云端 D1，且教师端学情看板与薄弱错词榜实时更新。
