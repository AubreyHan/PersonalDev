# FilePurger 产品需求文档 (PRD)

---

## 1. 产品概述 (Product Overview)

### 1.1 背景与痛点
对于开发者、设计师和重度电脑用户而言，不同目录的文件流转生命周期截然不同：
1. **下载目录 (Downloads)**: 充斥着单次使用的安装包（`.dmg`, `.exe`）、文档与解压残留，需要超过 14 天自动归档或扔入废纸篓。
2. **构建与临时产物 (Build / Cache / Logs)**: 工程中的 `.log`, `.tmp`, `core.*` 产生频繁且体积庞大，需要一旦生成或超过 24 小时立即清除，无需经过废纸篓占用二次空间。
3. **重要工作成果与归档 (Project Assets)**: 超过 90 天未修改的大体积视频或源工程包，直接删除风险高，更适合自动压缩为 `.zip` 归档到冷备份路径（如移动硬盘或归档目录）。
4. **现有清理软件的致命缺陷**:
   - 规则死板：仅支持一键“全盘大扫除”，无法为不同文件夹定制不同的生命周期策略。
   - 匹配能力简陋：不支持正则表达式，无法精准匹配形如 `screenshot-202[0-9]{5}\.png` 或 `app-v\d+\.\d+\.dmg` 的模式文件。
   - 动作单一：除了删除无法做压缩归档或分类移动。
   - 缺乏自动化常驻：要么每次必须手动打开软件点扫描，要么就是臃肿的流氓杀毒全家桶后台偷跑。

### 1.2 产品定位与核心价值
**FilePurger** 定位为**“深度自定义通用文件清理与自动化管理引擎”**。
以**“轻量系统托盘常驻 + 独立配置面板”**为形态，底层基于 Rust 实现极致轻量的内存常驻与并发处理。
核心理念是：**让每个文件夹拥有自己的自动化保洁管家**。
用户通过多目录独立策略卡片，自由组合高级正则/通配符规则、多样化动作（回收站/动态归档/Zip压缩/永久粉碎）与混合调度（定时/变动监听/托盘触发），实现完全无人值守且绝对安全的磁盘自我净化。

## 2. 目标用户与使用场景 (User Personas & Scenarios)

### 2.1 目标用户画像
- **开发者 / DevOps**: 机器上有多个代码工程、临时镜像和构建输出目录，需要精细化根据文件名正则和修改时间，秒级触发构建垃圾清理。
- **创意设计 / 视音频工作者**: 经常产出大体积 `.mov`, `.psd`, `.blend` 缓存，希望超过 30 天的素材能自动 Zip 压缩并按年份月份归档到外置硬盘。
- **追求秩序的极客 / 高级电脑用户**: 厌恶杂乱的“下载”和“桌面”文件夹，希望软件常驻托盘，静默监听并在后台优雅完成自动维护，且内存占用极低。

### 2.2 典型用例流程 (User Journeys)

#### 场景 A：下载目录日常保洁与软性清理 (Downloads Housekeeping)
1. 用户在 FilePurger 中为 `~/Downloads` 添加策略：“下载目录双周保洁”。
2. 配置规则：
   - 条件 1：最后修改时间 > 14 天。
   - 条件 2：Glob 通配符匹配 `*.{dmg,pkg,exe,msi,iso,zip}`。
   - 条件 3：排除文件名包含 `keep_` 或以 `important-` 开头的文件。
3. 设定动作：**移入系统废纸篓 (Trash)**。
4. 设定调度：**定时计划 (Cron)**：每周五下午 18:00 自动执行一次，并在完成后推送系统通知：“已为下载目录移入 12 个过期安装包至废纸篓，释放 8.4GB”。

#### 场景 B：工程日志与临时文件即时粉碎 (Logs & Temp Realtime Purge)
1. 用户为自动化日志目录 `~/app_logs` 添加策略：“日志即刻清理”。
2. 配置规则：
   - 条件：正则表达式 `^error_\d{8}\.log$`，最后修改时间 > 48 小时，或单文件体积 > 500MB。
3. 设定动作：**永久直接物理粉碎 (Hard Delete)**（跳过废纸篓，快速释放磁盘）。
4. 设定调度：**实时文件变动监听 (File Watcher)**：开启变动监听，内置 5 秒防抖（Debounce）。新日志一旦达到条件自动擦除，始终保持目录轻量。

#### 场景 C：冷数据智能 Zip 压缩归档 (Cold Assets Archive)
1. 用户为设计导出目录 `~/DesignExports` 添加策略：“半年旧设计归档”。
2. 配置规则：最后访问时间 > 180 天，且单文件 > 50MB。
3. 设定动作：**压缩为 Zip 归档并移动**，目标路径模板为 `/Volumes/Backup/Archives/{YYYY}/{MM}/`，压缩成功后自动清除原文件。
4. 设定调度：每月 1 号执行一次，支持随时在托盘右键“立即执行该策略”。

## 3. 功能需求规格 (Functional Requirements)

### 3.1 多目录独立策略体系 (FR-1: Policy Management)
- **FR-1.1 策略卡片式管理**: 支持创建多条独立策略，每条策略拥有：策略名称、启用开关、目标监控目录（单个或多个）、规则集、处置动作与调度方式。
- **FR-1.2 快捷目录注入**: 预设系统常用目录快捷选择（如 Downloads, Desktop, Temp, Caches）。
- **FR-1.3 系统保护目录阻断 (PathGuard)**:
  - 严禁添加操作系统核心目录作为策略目标（macOS: `/`, `/System`, `/Library`, `/Applications`, `~/.Trash`；Windows: `C:\Windows`, `C:\Program Files`）。
  - 若用户尝试添加受保护路径，界面显式拦截并阻断保存。
- **FR-1.4 策略配置导入与导出**: 支持全量策略以标准 JSON / YAML 文件导入导出，便于多台设备快速同步与备份。

### 3.2 高级复合匹配引擎 (FR-2: Advanced Matching Engine)
- **FR-2.1 多模式文件名匹配**:
  - **Glob 通配符**: 支持 `*.{dmg,zip}`, `build/**/temp_*` 等现代 Glob 语法。
  - **正则表达式 (Regex)**: 完整支持 PCRE 风格的 Rust 语法正则表达式（例如 `^backup_\d{4}-\d{2}-\d{2}\.tar\.gz$`）。
  - **匹配取反 (Invert Match)**: 支持“仅匹配”或“排除匹配（黑白名单）”。
- **FR-2.2 多维时间条件**:
  - 判定维度支持：最后修改时间 (`mtime`)、最后访问时间 (`atime`)、创建时间 (`ctime/btime`)。
  - 时间单位支持：分钟、小时、天、周、月。
  - 支持区间表达式（例如：大于 30 天 且 小于 365 天）。
- **FR-2.3 尺寸阈值与文件类型**:
  - 文件大小区间：设定下限（如 `> 100MB`）与上限（可选）。
  - 目录递归深度：支持限制最大递归层级（例如仅扫描 1 级深度，或无限递归子目录）。
  - 排除隐藏文件与系统隐藏元数据（如 `.DS_Store`, `Thumbs.db`, `.git/`）。
- **FR-2.4 规则组合逻辑 (AND / OR)**:
  - 支持“必须同时满足所有条件 (AND)”或“满足任一条件即可 (OR)”。

### 3.3 多样化处置动作流 (FR-3: Action Handlers)
每个策略可独立绑定一种具体的处置动作：
- **FR-3.1 移入系统废纸篓 (Move to Trash)**:
  - 默认动作。调用系统原生 API 移入废纸篓/回收站，支持外置磁盘回收区。误删可在系统废纸篓中无损一键还原。
- **FR-3.2 动态归档移动 (Archive Move)**:
  - 移动到目标归档目录。
  - 支持路径模板变量替换：`{YYYY}`（年）、`{MM}`（月）、`{DD}`（日）、`{EXT}`（后缀）。
  - 若目标目录不存在，自动递归创建。重名文件支持自动序号防覆盖（如 `file(1).dmg`）。
- **FR-3.3 Zip 压缩归档 (Compress & Archive)**:
  - 将命中文件按批次流式打包为 `.zip` 压缩文件并存放到指定归档目录，原文件在压缩校验成功后安全移除。
  - 支持指定压缩级别（快速 / 最佳压缩）。
- **FR-3.4 永久物理直接粉碎 (Hard Delete)**:
  - 跳过废纸篓直接擦除。
  - **安全锁保护**: 开启此动作时，界面强制弹出高危警告并要求输入确认字样；同时 PathGuard 执行最高级安全检查。

### 3.4 全能混合调度引擎 (FR-4: Hybrid Scheduling)
- **FR-4.1 定时计划调度 (Cron Scheduler)**:
  - 内置便捷周期预选（如“每小时整点”、“每天 00:00”、“每周日 23:00”）。
  - 支持标准 5 位/6 位 Cron 表达式输入，适应高阶精细化时间编排。
- **FR-4.2 实时文件变动监听 (Realtime File Watcher)**:
  - 基于操作系统原生异步事件（macOS FSEvents, Windows ReadDirectoryChangesW, Linux inotify）。
  - 具备**智能防抖机制 (Debounce)**（可配置 3~30 秒防抖），确保正在大文件写入或下载中的文件不会被过早捕获处理。
- **FR-4.3 托盘与面板即时手动触发 (Manual Trigger)**:
  - 任何策略均可在需要时即刻手动“一键跑批”。

### 3.5 系统托盘常驻与极简交互 (FR-5: System Tray & UI)
- **FR-5.1 托盘图标与状态指示**:
  - macOS 顶部状态栏 / Windows 任务栏托盘常驻，极低资源占用。
  - 托盘图标状态：正常待命、正在执行中（微旋转动画）、告警。
- **FR-5.2 托盘快捷右键菜单**:
  - 菜单项：打开主控制台、立即执行全部启用策略、各策略快捷触发子项、暂停/恢复后台监听、退出。
- **FR-5.3 独立管理控制台 (Dashboard Window)**:
  - 支持多标签页面：策略管理中心、规则构建与沙盒测试器、实时运行日志与历史审计、系统设置。
  - 支持全局快捷键呼出控制台。

### 3.6 规则沙盒调试器与安全预览 (FR-6: Sandbox & Preview)
- **FR-6.1 正则与规则在线沙盒测试**:
  - 用户编写正则表达式或通配符时，提供内嵌测试器：可输入测试文件名实时查看是否命中，并给出命中原因。
- **FR-6.2 真实目录 Dry-Run 预演**:
  - 在正式保存并执行前，提供「试运行预览 (Dry-Run)」按钮。
  - 仅扫描目标目录并高亮列出所有当前符合规则的文件清单与预计释放空间，**绝不执行实际移动或删除**，让用户完全安心。

### 3.7 审计日志与追溯管理 (FR-7: Audit & History)
- **FR-7.1 本地全量审计日志**:
  - 记录每次触发的时间戳、触发类型（定时/变动/手动）、触发策略名、处理文件数、释放容量、处置动作及详细文件清单。
- **FR-7.2 异常跳过与告警追踪**:
  - 针对无权限、正被独占占用的文件自动跳过，并写入详细异常日志供用户查阅。

## 4. 非功能需求 (Non-Functional Requirements)

### 4.1 性能指标
- **常驻后台资源占用**: 托盘常驻且挂载 5 个以上 Watcher 时，CPU 占用率日常接近 0.0%，内存占用（RSS）稳定在 **40MB 以内**。
- **文件扫描与规则评估**: 100,000 个文件的目录在现代 NVMe SSD 上完成正则与时间匹配评估耗时 **≤ 2.5 秒**。
- **UI 响应灵敏度**: 预览列表集成 TanStack Virtual 虚拟滚动，即使匹配出 50,000+ 文件仍可 60fps 丝滑滚动与多维排序。

### 4.2 跨平台兼容性
- **macOS**: 支持 macOS 12 Monterey 及以上（原生支持 Apple Silicon M 系列与 Intel x64 架构）。
- **Windows**: 支持 Windows 10 / 11（x64 与 ARM64）。
- **Linux**: 支持现代主流发行版（Ubuntu / Fedora / Arch Linux，具备 system tray 支持的桌面环境）。

## 5. 明确不做的范围 (Non-Goals)

1. **不做云端数据同步**: 所有的规则配置、策略数据和审计流水均纯本地持久化，杜绝敏感文件路径上传云端引发隐私风险。
2. **不做 Windows 注册表扫描**: 专注文件系统级别的深度保洁与自动化生命周期管理，不涉足脆弱的系统注册表清理。
3. **不做强制擦除正在读写文件的危险行为**: 对于被外部进程锁定的文件，坚决采用跳过并告警机制，绝不强制杀死外部句柄导致数据损坏。

## 6. 详细验收标准清单 (Acceptance Criteria)

- [ ] **AC-1 策略独立性验证**: 创建策略 A (监控 Downloads 移入回收站) 与策略 B (监控 Logs 直接物理粉碎)，两者的规则集、动作与触发方式互不影响，各自正常运转。
- [ ] **AC-2 正则与 Glob 匹配准确性**: 配置正则 `^test_(\d+)\.tmp$` 并指定天数 > 3 天，能够 100% 精确匹配目标格式文件，而不命中 `test.tmp` 或刚生成的文件。
- [ ] **AC-3 处置动作全覆盖验证**:
  - 废纸篓动作：文件安全进入系统废纸篓，可原路放回。
  - 归档动作：文件按指定 `{YYYY}/{MM}` 模板被移动至新目录。
  - Zip 动作：目标文件被打包为 `.zip`，源文件清除，压缩包完整解压无损坏。
  - 物理直接粉碎：跳过废纸篓彻底清除，且受到 PathGuard 阻断保护。
- [ ] **AC-4 变动监听与防抖**: 开启 File Watcher 后，在目标目录快速连续创建 10 个文件，系统仅在防抖周期结束后聚合派发一次处理，CPU 无瞬时飙升。
- [ ] **AC-5 托盘与后台常驻**: 最小化或关闭主控制台窗口时，应用收起至系统托盘继续常驻工作，内存稳定在 40MB 以内；点击托盘菜单可重新唤出控制台。
- [ ] **AC-6 核心系统路径防御**: 尝试在策略中添加 `/System` 或 `C:\Windows` 时，系统在前端与后端双重拦截并弹窗拒绝。
