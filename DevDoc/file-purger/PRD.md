# FilePurger 产品需求文档 (PRD)

---

## 1. 产品概述 (Product Overview)

### 1.1 背景与痛点
日常电脑使用过程中，用户的磁盘空间往往被大量“沉睡文件”悄然蚕食：
1. **下载目录堆积**: 浏览器下载的安装包（`.dmg`, `.exe`, `.pkg`）、压缩包（`.zip`, `.rar`, `.tar.gz`）、单次查阅的临时文档半年未碰，占据数十乃至上百 GB。
2. **多媒体与临时工程废弃物**: 导出后未清理的高清视频剪辑中间文件、渲染缓存、大体积日志等。
3. **系统自带清理工具局限**: 系统自带清理功能要么规则死板（无法自由指定路径与时间），要么缺少精细化预览，让用户心生误删恐慌。
4. **现有第三方软件笨重或高风险**: 许多老牌系统清理工具捆绑广告、后台常驻占用大量资源，或直接物理彻底擦除文件，带来不可挽回的数据丢失风险。

### 1.2 产品定位与目标
**FilePurger** 是一款以**“极速扫描”、“复合规则筛选”与“零顾虑安全删除（默认移入废纸篓）”**为核心特性的跨平台现代桌面端轻量工具。
- 帮助用户快速发现指定目录中的“高龄”、“大体积”、“冗余类型”冷文件。
- 提供直观清爽的预览对比和批量勾选操作。
- 绝不粗暴强删，默认移入系统废纸篓，配合轻量定期提醒，让磁盘空间管理轻松、安心、高效。

## 2. 目标用户与使用场景 (User Personas & Scenarios)

### 2.1 典型用户画像
- **开发者与极客**: 磁盘空间经常被大体积安装包、镜像、旧日志、归档压缩包挤爆，渴望高性能、无后台流氓常驻、可精细配置规则的干净工具。
- **数字内容创作者 / 设计师**: 经常处理几百 MB 到几 GB 的临时素材、导出渲染缓存，需要定期按时间和大小揪出数月未修改的文件。
- **普通电脑用户 / 上班族**: “下载”或“桌面”文件夹长期塞满各种只用过一次的文档和安装文件，不知从何整理，需要简单一键扫一扫、安全扔进废纸篓。

### 2.2 典型用例流程 (User Journey)
1. **场景 A：下载目录定期大扫除（快速推荐模式）**
   - 用户打开 FilePurger，默认选定或手动添加 `Downloads` 文件夹。
   - 勾选内置预设模板：“30 天以上未修改且大于 50MB 的安装包与压缩包”。
   - 点击「开始扫描」，2 秒内呈现命中文件列表（总计 18GB，42 个文件）。
   - 用户在界面按文件大小由大到小查看，取消勾选 1 个仍想保留的离线包，点击「安全清理」。
   - 文件瞬间被移入 macOS 废纸篓，界面显示释放空间总量与耗时。
2. **场景 B：自定义复杂目录深度清理（专家自定义模式）**
   - 用户选择外部移动硬盘或项目备份目录。
   - 设定复合规则：未修改天数 ≥ 180 天，扩展名匹配 `*.log, *.tmp, *.iso, *.bak`，大小 ≥ 10MB。
   - 设定排除目录：白名单排除 `keep_forever/`。
   - 扫描预览后批量清理，随时可点击“在访达/资源管理器中查看”确认文件上下文。
3. **场景 C：轻量周度清理提醒**
   - 用户开启“每周五下午提醒扫描下载目录”。
   - 达到时间节点且应用处于后台或通过系统计划触发轻量巡查，若发现超过 10GB 候选旧文件，弹出原生桌面通知：“FilePurger 发现下载目录有 12.4GB 旧文件建议清理”。
   - 用户点击通知唤起应用完成核对与清理，非静默强删。

## 3. 功能需求规格 (Functional Requirements)

### 3.1 目录管理与选择 (FR-1)
- **FR-1.1 常用目录一键添加**: 预设常用快速访问目录（如 `用户下载目录 Downloads`、`桌面 Desktop`、`临时缓存`）。
- **FR-1.2 自定义路径选择**: 支持系统原生文件夹选取弹窗（Tauri File Dialog）或拖拽文件夹直接添加到扫描目标区。
- **FR-1.3 关键系统路径保护与封锁**:
  - 严禁用户扫描或清理系统级根目录与核心系统路径（例如 macOS 下 `/`, `/System`, `/Library`, `/Applications`；Windows 下 `C:\Windows`, `C:\Program Files`）。
  - 若用户尝试添加受保护路径，界面给出明确警告并阻止加入。

### 3.2 复合清理规则引擎 (FR-2)
- **FR-2.1 时间维度条件**:
  - 支持按**最后修改时间 (mtime)** 或 **最后访问/读取时间 (atime)**。
  - 支持预设快捷天数（如 7 天、30 天、90 天、180 天、1 年）及自定义天数输入。
- **FR-2.2 文件类型/扩展名过滤**:
  - 支持类型分组快速勾选：
    - 安装与镜像包：`dmg, pkg, exe, msi, iso`
    - 归档压缩包：`zip, tar, gz, 7z, rar`
    - 临时与日志文件：`log, tmp, cache, bak, old`
    - 自定义扩展名模式（通配符支持，例如 `*.mp4`, `temp_*.*`）。
  - 模式支持：全部文件 / 仅匹配指定扩展名 / 排除指定扩展名。
- **FR-2.3 文件大小阈值**:
  - 最小值过滤：例如仅扫描大于等于 `10MB`, `50MB`, `100MB`, `1GB` 或任意数值的文件。
  - 最大值上限（可选）：用于精确限定区间。
- **FR-2.4 排除与白名单 (Ignore List)**:
  - 支持路径黑名单/排除项：自动忽略隐藏文件（可选）、系统点文件（如 `.DS_Store`, `desktop.ini`）、版本控制目录（如 `.git/`, `.svn/`）。
  - 支持自定义排除目录或文件名关键字。
- **FR-2.5 规则预设保存与加载**:
  - 用户可将当前配置保存为“清理预设”（如“日常下载瘦身”、“日志归档清理”），随时快速调用。

### 3.3 极速扫描与实时反馈 (FR-3)
- **FR-3.1 高性能多线程扫描**:
  - 底层基于 Rust 多线程并行递归遍历，避免阻塞 UI 交互。
- **FR-3.2 实时流式进度反馈**:
  - 扫描过程中界面实时展示已扫描文件数、已匹配旧文件数、匹配总体积、当前扫描路径。
  - 支持随时中止/取消扫描，已扫描出来的结果保留供查看。

### 3.4 可视化结果审阅与交互 (FR-4)
- **FR-4.1 清单列表与多维排序**:
  - 呈现文件列表表格/卡片：文件名、所在路径、文件大小、最后修改时间、扩展名图标。
  - 支持按「大小降序（默认）」、「最后修改时间最久」、「文件名称」点击表头排序。
- **FR-4.2 筛选与批量选择**:
  - 顶部统计看板：总匹配文件数、总占用磁盘空间、当前已勾选文件数及已勾选大小。
  - 支持全选 / 反选 / 仅选中 >100MB / 智能全选推荐。
- **FR-4.3 定位与预览能力**:
  - 每项文件提供操作快捷按钮：
    - **在文件管理器中定位**: 调用系统原生 Finder / Explorer 打开并选中该文件。
    - **快速预览/查看详情**: 查看文件完整路径与扩展元数据。

### 3.5 安全清理执行引擎 (FR-5)
- **FR-5.1 原生回收站移入机制 (核心)**:
  - 默认调用系统废纸篓（macOS Trash / Windows Recycle Bin）API。
  - 执行过程保证原子安全，文件移动至回收站后其原始路径被清除，用户可随时在废纸篓中查阅并按需原路恢复。
- **FR-5.2 执行进度与异常容错**:
  - 批量删除时展示进度条。
  - 针对无权限、被其他进程占用锁定的文件跳过并记录告警，不导致整体批次中断崩溃。
- **FR-5.3 结果汇总与反馈**:
  - 清理完成后弹出成果面板：本次共移入回收站 X 个文件，成功为磁盘释放 Y GB 空间，耗时 Z 秒。

### 3.6 历史审计与轻量计划提醒 (FR-6)
- **FR-6.1 清理历史与审计记录**:
  - 本地记录每次清理批次（时间戳、清理文件数、释放容量、目录源）。
  - 用户可在“历史记录”标签页中查看累计已释放总空间趋势。
- **FR-6.2 轻量定时扫描提醒配置**:
  - 用户可在设置中启用“定时检查提醒”（频率：每周 / 每月；指定目标目录）。
  - 到期后仅执行后台轻量预估扫描，并通过桌面通知告知用户清理建议，点击通知唤醒主界面，**坚决不执行静默删除**。

## 4. 非功能需求 (Non-Functional Requirements)

### 4.1 性能指标
- **扫描吞吐量**: 100,000 个文件的目录在现代 SSD 磁盘上扫描并在内存完成规则匹配耗时 ≤ 3 秒。
- **内存占用**: 扫描 200,000 个文件列表并呈现在前端虚拟滚动列表中，内存占用峰值不超过 120MB，常驻内存 < 50MB。
- **界面响应**: 结果列表采用虚拟滚动（Virtual List），千级/万级文件渲染流畅（帧率稳定在 60fps），无任何输入卡顿。

### 4.2 平台兼容性与安全
- **操作系统**: macOS 12+ (Apple Silicon & Intel)、Windows 10 / 11 (x64 & ARM64)、现代主流 Linux 桌面。
- **安全沙箱与权限**: 遵守 macOS 辅助权限及沙箱规范，申请必要文件读写与废纸篓访问权限。
- **数据隐私**: 所有文件路径、元数据与操作记录纯本地处理，绝不上传任何网络服务器。

## 5. 明确不做的范围 (Non-Goals)

1. **不做彻底粉碎与磁盘扇区擦除**: 本软件定位为生活/工作场景的磁盘空间管理助手，核心理念是安全无压，不提供 DoD 5220.22-M 级别的高级数据擦除粉碎算法。
2. **不做系统注册表或深度应用关联清理**: 专注文件级别（Files & Folders）的旧文件与冗余文件扫描，不涉及 Windows 注册表扫描或软件深度卸载残留追踪。
3. **不做后台完全静默自动删除**: 即使配置了定时提醒，也必须经过用户主动确认才能将文件移入废纸篓，杜绝 AI/算法误判导致用户珍贵数据在不知情下丢失。

## 6. 验收标准清单 (Acceptance Criteria)

- [ ] **AC-1 目录添加与边界防护**: 能够通过系统选择器或拖入添加任意合法用户目录；尝试添加 `/System` 或 `C:\Windows` 时弹窗拦截并提示拒绝。
- [ ] **AC-2 规则组合生效**: 同时指定「修改时间 > 60 天」、「大小 > 100MB」、「后缀为 dmg, zip」时，扫描出的结果必须 100% 严格符合这 3 项交集条件。
- [ ] **AC-3 原生回收站行为验证**: 勾选指定测试文件执行清理后，文件在原目录消失，在系统废纸篓/回收站中完好存在，点击“放回原处”可完美还原。
- [ ] **AC-4 异常与占用容错**: 当目录中存在被锁定的文件或无读取权限的文件时，扫描与删除进程不闪退，能清晰在结果报告中标记“跳过”及原因。
- [ ] **AC-5 历史审计留痕**: 执行清理后，“清理历史”页面立即更新最新一条记录，准确记载释放容量、时间与文件总数。
