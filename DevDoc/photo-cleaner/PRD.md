# PhotoCleaner 产品需求文档 (PRD)

> 状态：第一期定稿 — 2026-11-11

---

## 1. 产品概述 (Product Overview)

### 1.1 背景与核心痛点
随着 iPhone 与相机多年拍摄积累，Apple 原生“照片 (Photos.app)”与 iCloud 图库往往堆积数万张照片、连拍废片、临时截图与大体积视频：
1. **全量清理挫败感极强**: 面对时间线上连续几万张照片，用户很难一次性抽出数小时从头整理到尾，往往半途而废。
2. **原生相册缺乏高频筛片流**: macOS 原生“照片.app”偏重浏览与编辑，缺乏面向清理场景的“按月-日跨年份聚合”、“366 天打卡进度追踪”、“当日相似废片同屏对比一键淘汰”以及“跨批次待删暂存篮”。
3. **PhotoKit 删除弹窗打断节奏**: 在 macOS 第三方应用中若逐张调用删除接口，每次均会触发系统强制确认弹窗，严重割裂键盘快审体验。
4. **iCloud 优化存储隐患**: 许多全库扫描类清理软件在后台强行拉取全量原图计算哈希或特征，导致开启“优化 Mac 储存空间”的用户本地磁盘瞬间爆满。

### 1.2 产品定位与核心价值
**PhotoCleaner** 是一款专为 **macOS 系统照片图库**设计的原生渐进式清理桌面应用。
核心理念是将庞大相册按日历拆解为 **366 个“月-日（MM-DD）”切片**（例如 `8月13日` 聚合展示 2015~2026 每年 8月13日 的全部影像）：
- **默认聚焦今日，自由穿梭全年**: 打开即展示“当年今日”，同时可在 366 天日历面板点选任意一天逐块攻克。
- **增量感知的进度记忆**: 记录每个月-日已审阅的照片 ID 快照；明年同一天拍了新照片或补导旧照时自动标记“有新增待审”。
- **三视图极速筛片**: 年份分组网格 + 空格大图快审 + Vision 当日相似组同屏并排挑片。
- **零误删焦虑 + 单次确认提交**: 收藏（❤️）照片免弹窗锁定免疫删除；全局待删暂存篮跨日期累积，最后一键提交仅触发 1 次系统确认并安全移入原生“最近删除”。

## 2. 核心用户旅程 (User Journey)

1. **启动与授权**:
   - 用户从 Dock 或应用文件夹打开 `PhotoCleaner`（首次运行引导授予“照片图库完全访问权限”）。
   - 应用在毫秒级构建全库 366 天内存日期索引，默认进入**今天（如 11月11日）**，展示历年 `11月11日` 的照片与视频。
2. **浏览与过滤**:
   - 主区域按年份倒序分组（`2026年11月11日`、`2025年11月11日`...）展示缩略图网格。
   - 用户可点击顶部过滤胶囊（如【仅截屏】或【大体积优先】）快速框选明显无用的截图与大视频加入待删暂存篮。
3. **相似组同屏挑片**:
   - 网格中同一天高度相似的连拍/多张试拍保持时间顺序平铺，并由同组高亮色框标注【相似组 · 4张 | 对比此组】。
   - 点击【对比此组】进入并排对比视图，同步放大查看对焦与表情，勾选最佳 1 张，点击【保留选中，其余移入待删篮】。
4. **空格大图快审与收藏联动**:
   - 点击任意照片按 `Space` 进入大图快审模式，左手 `F` 点亮好照片的原生“收藏 ❤️”，右手 `← / →` 翻片、按 `Delete`（或 `X`）将废片丢入待删暂存篮；遇到已带 ❤️ 的照片误按删除时，系统自动跳过并给出轻提示保护。
5. **标记当日完成与跨日连续清理**:
   - 审阅完 `11月11日` 后点击【标记 11月11日 已整理】（或点击【下一待整理日期】继续整理 `8月13日`）。
   - 多天挑出的待删照片持续累积在底部/侧边的**全局待删暂存篮**中（实时显示如 `待删 38 项 · 预计释放 2.4 GB`）。
6. **一键批量提交清理**:
   - 点击暂存篮【提交清理】，触发 **1 次** macOS 系统原生删除确认框；确认后 38 项资产统一移入 Apple 照片“最近删除”，统计面板累加已清理数量与释放容量。
   - 关闭应用窗口，进程彻底退出，零后台驻留。

## 3. 功能需求规格 (Functional Requirements)

### 3.1 图库接入与权限引导 (FR-1: PhotoKit Authorization & Library Scope)
- **FR-1.1 系统图库接入**: 通过 `PHPhotoLibrary.shared()` 接入 macOS 当前设定的“系统照片图库”。
- **FR-1.2 权限状态引导**:
  - 首次启动请求 `.readWrite` 完整照片访问权限；
  - 若用户拒绝或仅授予受限权限（Limited），展示清晰的权限引导页并提供一键跳转【系统设置 -> 隐私与安全性 -> 照片】按钮。
- **FR-1.3 实时图库变更监听**: 注册 `PHPhotoLibraryChangeObserver`，当用户在原生“照片.app”中增删照片、修改收藏状态或恢复照片时，应用内网格、计数与暂存篮状态实时自动同步。
- **FR-1.4 隐藏相簿隐私策略**:
  - 默认排除原生“已隐藏 (Hidden)”相簿中的资产（`includeHiddenAssets = false`）；
  - 在应用【设置 (`⌘,` )】中提供“包含已隐藏照片”开关（默认关闭），用户手动开启后方可纳入索引与展示。
- **FR-1.5 iCloud 优化存储兼容**:
  - 网格缩略图加载与相似图特征提取**严格仅使用本地可用缩略图/中等预览图**，禁止在列表浏览或后台分析时静默触发大批量 iCloud 原图下载；
  - 当资产原片仅存于 iCloud 时，缩略图显示轻量云端角标；仅当用户主动进入该资产的大图快审、同屏高清对比或点击播放视频时，允许通过网络流式拉取高清资源（`isNetworkAccessAllowed = true`）并显示环形加载进度。

### 3.2 366 天日历面板与增量进度管理 (FR-2: 366-Day Slice & Progress Engine)
- **FR-2.1 默认定位与任意跳转**:
  - 每次冷启动默认选中系统当前日期对应的“月-日”（如 `11-11`）；
  - 左侧常驻（可折叠）全年 **12 个月 / 366 天（固定包含 `02-29` 闰日）** 导航面板，支持点击任意月-日（如 `08-13`）即时切换，同时提供顶部日期快速选择器与【回到今天】、【下一个待整理日】快捷按钮。
- **FR-2.2 日期归属口径**:
  - 按系统当前日历时区（`Calendar.current`）提取 `PHAsset.creationDate` 的 `month` 与 `day`，聚合所有年份同月同日的照片、Live Photo 与视频。
- **FR-2.3 四态进度定义**:
  每个月-日切片根据当前图库资产集合 $A_{\text{current}}$ 与本地持久化的“已审资产 ID 集合” $S_{\text{reviewed}}$ 自动计算状态：
  1. **空置 (`empty`)**: $A_{\text{current}} = \emptyset$（历年该日无任何照片/视频，日历格置灰，跳转“下一待整理日”时自动跳过）；
  2. **待整理 (`pending`)**: $A_{\text{current}} \neq \emptyset$ 且该日期从未被标记完成（$S_{\text{reviewed}} = \emptyset$）；
  3. **已整理 (`completed`)**: $A_{\text{current}} \neq \emptyset$ 且 $A_{\text{current}} \subseteq S_{\text{reviewed}}$（当前该日所有存量资产均在已审集合内，日历格显示绿色完成标识）；
  4. **有新增待审 (`hasNew`)**: 该日期曾标记完成（$S_{\text{reviewed}} \neq \emptyset$），但存在新增未审资产 $A_{\text{new}} = A_{\text{current}} \setminus S_{\text{reviewed}} \neq \emptyset$（如明年今日拍了新照，或从相机补导了往年该日照片；日历格显示蓝/橙点新增标识）。
- **FR-2.4 完成态触发与重置**:
  - 用户点击当前日期工具栏的【完成当日整理】按钮时，将当前日期下所有未被删除的存量资产 `localIdentifier` 并入 $S_{\text{reviewed}}$（注：若当前日期仍有资产躺在“待删暂存篮”尚未提交，记入时排除暂存篮内资产，或提示先提交/确认保留）；
  - 支持对已整理日期点击【重置为未整理】（清空该日的 $S_{\text{reviewed}}$）。
- **FR-2.5 全局清理统计看板**:
  - 侧栏顶部展示：`已整理天数 / 有照片总天数` 进度条、`累计清理照片/视频数`、`累计释放空间 (MB/GB)`。

### 3.3 年份分组网格与多维筛选 (FR-3: Year-Grouped Grid & Filters)
- **FR-3.1 按年份倒序分组**:
  - 主视图将选中月-日的资产按年份**倒序**（如 `2026年8月13日` → `2025年8月13日` → `2020年8月13日`）分组展示，组头显示具体日期、星期、当年张数及【全选本年未收藏项】快捷操作；
  - 同一年份内按拍摄时间升序（或可切换倒序）排列。
- **FR-3.2 缩略图信息角标**:
  - 清晰标注：视频时长（如 `01:24`）、Live Photo 实况图标、截屏标识、收藏红心 `❤️`、单文件体积（当大于设定阈值如 `> 20MB` 或开启体积显示时）、`新增未审` 角标（当日期处于 `hasNew` 状态时）、`已在待删篮` 半透明红色遮罩与删除角标。
- **FR-3.3 顶部快捷过滤栏**:
  - 支持单选/组合过滤当前月-日资产：
    - `全部 (N)`
    - `仅照片` / `仅视频`
    - `仅截屏与录屏`（匹配 `.photoScreenshot` 或屏幕录制媒体子类型）
    - `大体积 (>20MB)`（支持按体积从大到小排序检视）
    - `相似/连拍组`（仅过滤出当天命中相似聚类的组）
    - `仅看新增`（仅在日期状态为 `hasNew` 时出现，只看上次整理后新加入的照片）
- **FR-3.4 多选与框选交互**:
  - 支持单击选中、`Shift + 单击` 区间连选、`⌘ + 单击` 增减多选、鼠标拖拽橡皮筋框选，选中后可一键加入/移出待删暂存篮。

### 3.4 大图快审流与原生相册联动 (FR-4: Quick Review & Native Sync)
- **FR-4.1 无缝进入与退出**:
  - 在网格选中任意资产按 `Space`（或双击缩略图）立即进入大图快审视图；再次按 `Space` 或 `Esc` 返回网格并保持焦点定位在当前最后审阅的资产上。
- **FR-4.2 原生媒体高保真播放**:
  - **静态图 / RAW**: 高清缩放查看（支持触控板双指缩放、双击 100% 放大与拖拽平移）；
  - **Live Photo**: 使用原生 `PHLivePhotoView` 渲染，支持悬停/按键（如长按或快捷键 `L`）带声音播放实况动态效果；
  - **视频**: 使用原生 `AVPlayerView` 流式播放（支持 HDR、慢动作帧率还原、进度条拖拽与静音/有声切换）。
- **FR-4.3 EXIF 详情检查栏**:
  - 右侧可开关信息栏（快捷键 `I`），展示：文件名、拍摄精确时间、文件精确大小（MB/GB）、像素分辨率、格式（HEIC/JPEG/ProRAW/MOV）、相机/手机型号与镜头焦段光圈、GPS 逆地理编码拍摄地点名称（若有）。
- **FR-4.4 同步原生“收藏 ❤️”**:
  - 按快捷键 `F`（或点击红心按钮）直接通过 `PHAssetChangeRequest` 修改系统相册中该资产的 `isFavorite` 属性（无需系统确认弹窗，即时双向同步至 Photos.app 与 iCloud）。
- **FR-4.5 全键盘极速审阅流**:
  - `←` / `→`：上一张 / 下一张（底部胶片条同步滚动并预加载前后高清图）；
  - `Delete` / `Backspace` / `X`：切换当前资产“加入待删暂存篮 / 从待删暂存篮移出”（自动跳到下一张可在设置开关，默认标记待删后自动前进到下一张以最大化效率）；
  - `⌘Z`：撤销最近一次加入/移出待删篮操作。

### 3.5 当日相似/连拍识别与同屏对比挑片 (FR-5: Per-Day Similarity & Compare View)
- **FR-5.1 按需单日轻量聚类**:
  - 当用户切换到某个月-日时，后台异步提取当天照片的本地缩略图：
    1. 优先合并原生连拍簇（相同 `burstIdentifier`）；
    2. 对同一年份、拍摄时间间隔在合理窗口内（或同日全部静态图/实况封面）运行 macOS 原生 `Vision` 框架 `VNGenerateImageFeaturePrintRequest` 计算特征距离，将高度相似的 2 张及以上照片归为一个“相似组 (Similarity Group)”。
- **FR-5.2 网格平铺不折叠展示**:
  - 网格内**严格保持原有时间顺序平铺，绝不折叠隐藏任何照片**；
  - 属于同一相似组的相邻/同组缩略图使用统一的分组视觉外框/连线标识，并在该组首张上方显示轻量胶囊条：【相似组 · N 张 | 对比此组】。
- **FR-5.3 同屏并排对比视图 (Compare View)**:
  - 点击【对比此组】（或在选中多张任意照片后按快捷键 `C` 主动发起对比），进入同屏多图对比界面（2~4 张并排网格，超过 4 张支持同组切换聚焦对比）；
  - 支持**同步缩放与同步平移 (Synced Zoom & Pan)**：放大其中一张查看人物眼睛/对焦清晰度时，其余对比照片自动同步放大至相同相对坐标区域；
  - 用户点击勾选本组要保留的 1~N 张最佳照片，点击【保留已选，其余移入待删篮】一键淘汰同组其余废片（自动遵守收藏 ❤️ 保护规则）。

### 3.6 双重安全防误删与全局待删暂存篮 (FR-6: Favorite Lock & Global Trash Basket)
- **FR-6.1 收藏 ❤️ 免弹窗锁定保护**:
  - 凡 `isFavorite == true` 的资产，默认处于**删除锁定保护状态**；
  - 无论在大图单删、网格多选批删，还是相似组“其余移入待删篮”中，系统均**自动跳过所有已收藏资产**，不弹出模态确认框打断操作，仅在界面底部/顶部弹出非阻塞轻提示（Toast）：*“已自动跳过 N 张收藏 ❤️ 照片；如需删除请先按 F 取消收藏”*；
  - 若用户在某资产已被放入待删暂存篮后又对其点亮了“收藏 ❤️”，该资产自动从待删暂存篮移出。
- **FR-6.2 全局跨日期暂存篮与本地持久化**:
  - 应用底部/侧边常驻【待删暂存篮】状态栏，实时显示当前暂存总项数与预计释放总字节数（如 `待删 24 项 · 预计释放 1.86 GB`）；
  - 点击可展开暂存篮抽屉，按日期分类检视所有待删缩略图，支持单张恢复（移出暂存篮）、【清空暂存篮（全部恢复保留）】；
  - 暂存篮内的 `localIdentifier` 列表每次变动即时写入本地持久化文件，支持用户连续清理多个月-日切片后再统一结算。
- **FR-6.3 一键批量提交系统删除**:
  - 点击【提交清理 (N 项)】时，应用汇总暂存篮内全部有效 `PHAsset` 一次性调用 `PHAssetChangeRequest.deleteAssets`；
  - 用户在弹出的 **唯一 1 次** macOS 系统级确认框中点击“删除”后：
    1. 照片/视频移入 Apple 原生相册“最近删除”（享有系统原生 30 天反悔期）；
    2. 应用清空暂存篮，并将本次成功删除的数量与实际文件体积累加写入本地历史清理统计。
- **FR-6.4 退出前未提交提醒**:
  - 当待删暂存篮非空且用户关闭窗口或按 `⌘Q` 退出应用时，弹出简洁三选一提示：
    - 【立即提交清理并退出】（推荐主按钮）
    - 【保留暂存篮，下次继续】（直接退出，下次启动自动恢复暂存篮内容）
    - 【取消】

### 3.7 应用生命周期与偏好设置 (FR-7: App Lifecycle & Preferences)
- **FR-7.1 纯按需桌面窗口形态**:
  - 标准 macOS 应用（显示在 Dock，支持窗口缩放、全屏与深浅色外观跟随系统）；
  - 关闭最后一个主窗口即彻底终止应用进程（`applicationShouldTerminateAfterLastWindowClosed = true`），**无后台守护进程、无菜单栏驻留、无推送通知打扰**。
- **FR-7.2 偏好设置 (`⌘,`)**:
  - 是否包含“已隐藏”相簿照片（默认：否）；
  - 大图快审标记待删后是否自动跳至下一张（默认：是）；
  - 相似图识别灵敏度（标准 / 严格 / 关闭自动识别）；
  - 重置统计数据或清空所有“已整理”进度记录（需二次确认）。

## 4. 非功能需求 (Non-Functional Requirements)

1. **性能与响应指标**:
   - **启动索引耗时**: 在包含 50,000 ~ 100,000 张资产的 Apple Silicon Mac 上，冷启动构建 366 天日期映射索引耗时 **≤ 300ms**，日期切换响应 **≤ 50ms**。
   - **网格帧率与内存**: 采用 `PHCachingImageManager` 滑动窗口预热与释放，年份分组网格滚动保持 **60/120fps**；常规浏览常驻内存控制在 **250MB 以内**。
   - **单日相似图聚类耗时**: 对单日 100 张照片基于本地缩略图执行 `Vision` 特征提取与聚类耗时 **≤ 1.5s**，全程在后台低优先级并发队列执行，绝不阻塞主线程 UI 交互。
2. **数据安全与隐私**:
   - **100% 纯离线端侧运行**: 无需联网账号，零外部网络请求（除 PhotoKit 自身按需从用户个人 iCloud 拉取预览流外），不收集任何遥测数据。
   - **零数据库破坏风险**: 严禁直接读写或篡改系统相册底层私有 `Photos.sqlite` 文件，一切读取、收藏修改与删除操作 100% 通过 Apple 官方公开的 `PhotoKit` API 完成，确保 iCloud 多端同步绝对安全。

---

## 5. 明确不做的边界 (Non-Goals — MVP 阶段)

为保持产品纯粹聚焦，第一期明确**不做**以下内容：
1. **不做全库一次性重复图大扫描**: 只针对当前选中的“月-日”切片做即时轻量相似分析，不做耗时数十分钟的全库后台重度 AI 扫描。
2. **不做照片编辑与滤镜修饰**: 不提供裁剪、调色、修图功能。
3. **不做复杂相簿整理与外部导出归档**: 不做新建/移动原生相簿管理，也不与外部 NAS 目录做哈希比对导入（NAS 归档由独立的 `Photo Album` 项目负责）。
4. **不做绕过系统“最近删除”的物理永久粉碎**: PhotoKit 官方安全模型规定第三方删除统一进入系统“最近删除”，清空“最近删除”交由用户在原生“照片.app”中自行决定或满 30 天自动清除。
5. **不做后台常驻、菜单栏小组件与定时弹窗提醒**。

## 6. 验收标准清单 (Acceptance Criteria)

- [ ] **AC-1 (今日默认与 366 日历)**: 启动应用默认展示当天月-日的跨年份照片；366 天面板（含 `02-29`）准确区分“空置、待整理、已整理、有新增待审”四种视觉状态。
- [ ] **AC-2 (增量新增检测)**: 将 `08-13` 标记为“已整理”后，向系统相册新增一张拍摄日期为任意年份 `08-13` 的照片，应用内 `08-13` 自动变为“有新增待审”且该照片带“新增”角标。
- [ ] **AC-3 (三视图闭环)**: 年份倒序网格、空格大图快审（含 Live Photo 播放、视频播放、EXIF 查看、`F` 键收藏同步）、当日相似组平铺框选与同屏同步缩放对比挑片均流畅可用。
- [ ] **AC-4 (收藏防误删保护)**: 对带 `❤️` 收藏的照片执行单删、框选删除或相似组“删除其余”时，均被免弹窗拦截跳过并弹出轻提示；取消收藏后可正常加入待删篮。
- [ ] **AC-5 (全局暂存篮与单次确认)**: 跨 3 个不同月-日分别标记若干待删照片后，点击一次【提交清理】，仅弹出 1 次 macOS 系统删除确认框，确认后全部移入系统相册“最近删除”，统计面板释放空间准确增加。
- [ ] **AC-6 (iCloud 安全策略)**: 在开启“优化 Mac 储存空间”的图库上浏览多个日期与运行相似图分析时，不会触发原图批量下载；点开云端大图/视频时平滑显示加载进度并正常预览。
- [ ] **AC-7 (零常驻退出)**: 暂存篮非空关闭窗口时正确弹出三选一提示；选择“保留暂存篮”重启应用后暂存篮内容完整恢复；关闭主窗口后进程彻底退出无残留。
