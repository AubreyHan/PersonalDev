# PhotoCleaner 产品需求文档 (PRD)

> 状态：第一期定稿 — 2026-11-11

---

## 1. 产品概述 (Product Overview)

### 1.1 背景与核心痛点
随着 iPhone 与相机多年拍摄积累，Apple 原生“照片 (Photos.app)”与 iCloud 图库往往堆积数万张照片、连拍废片、临时截图与大体积视频，同时用户相簿（Albums）也逐渐混乱：
1. **全量清理挫败感极强**: 面对时间线上连续几万张照片，用户很难一次性抽出数小时从头整理到尾，往往半途而废。
2. **原生相册缺乏高频筛片流**: macOS 原生“照片.app”偏重浏览与编辑，缺乏面向清理场景的“按月-日跨年份聚合”、“366 天打卡进度追踪”、“当日相似废片同屏对比一键淘汰”以及“跨批次待删暂存篮”。
3. **相簿归属不透明与空相簿残留**: 在原生相册中选中照片时，很难直观看到它“属于哪些相簿、不属于哪些相簿”并一键增删调整；随着照片被清理或移出，图库中还会遗留大量 0 张照片的空相簿与空相簿文件夹，手动逐一排查删除极其繁琐。
4. **PhotoKit 删除弹窗与 iCloud 优化存储隐患**: 逐张删除照片会反复触发系统弹窗割裂节奏；而后台全量拉取原图分析则会撑爆开启了“优化 Mac 储存空间”的本地磁盘。

### 1.2 产品定位与核心价值
**PhotoCleaner** 是一款专为 **macOS 系统照片图库**设计的原生渐进式清理与相簿整理桌面应用。
核心理念是将庞大相册按日历拆解为 **366 个“月-日（MM-DD）”切片**（例如 `8月13日` 聚合展示 2015~2026 每年 8月13日 的全部影像）：
- **默认聚焦今日，自由穿梭全年**: 打开即展示“当年今日”，同时可在 366 天日历面板点选任意一天逐块攻克。
- **增量感知的进度记忆**: 记录每个月-日已审阅的照片 ID 快照；明年同一天拍了新照片或补导旧照时自动标记“有新增待审”。
- **三视图极速筛片**: 年份分组网格 + 空格大图快审 + Vision 当日相似组同屏并排挑片。
- **相簿归属双向调整 + 空相簿即刻清零**: 选中单张或多张照片/视频即时展示“所属相簿 / 未加入相簿”，支持搜索、一键移入移出、直接新建相簿加入，并在启动及相簿变空时**自动即刻删除空相簿及连带变空的上级相簿文件夹**。
- **零误删焦虑 + 暂存篮单次提交**: 收藏（❤️）照片免弹窗锁定免疫删除；全局待删暂存篮跨日期累积，最后一键批量提交移入原生“最近删除”。

## 2. 核心用户旅程 (User Journey)

1. **启动、授权与历史空相簿自检**:
   - 用户打开 `PhotoCleaner`（首次运行授予“照片图库完全访问权限”）。
   - 应用在毫秒级构建全库 366 天内存日期索引与用户相簿归属反向索引；若检测到图库中存在历史遗留的空普通相簿或空相簿文件夹，立即发起自动清理。
   - 主界面默认进入**今天（如 11月11日）**，展示历年 `11月11日` 的照片与视频。
2. **浏览、过滤与调整相簿归属**:
   - 主区域按年份倒序分组展示缩略图网格；顶部支持【仅截屏】、【大体积】、【未入相簿】等快捷过滤。
   - 选中一张（或框选多张）照片/影片时，右侧检视栏清晰列出其 **【所属相簿】** 与 **【未加入相簿】**：用户可直接勾选将其加入 `旅行 / 2025日本`，或取消勾选从旧相簿移出，也可直接输入名称新建相簿并自动归入；若移出后某相簿（及其上级文件夹）变空，系统即刻自动删除该空相簿与空文件夹。
3. **相似组同屏挑片**:
   - 网格中同一天高度相似的连拍/多张试拍保持时间顺序平铺，并由同组高亮色框标注【相似组 · 4张 | 对比此组】。
   - 点击【对比此组】进入并排对比视图，同步放大查看对焦细节，勾选最佳 1 张，点击【保留选中，其余移入待删篮】。
4. **空格大图快审与收藏联动**:
   - 按 `Space` 进入大图快审模式，支持播放 Live Photo 与视频、查看 EXIF 详情、调整相簿归属，按 `F` 点亮原生“收藏 ❤️”，按 `Delete / X` 将废片丢入待删暂存篮；遇到已带 ❤️ 的照片误按删除时自动跳过并轻提示。
5. **跨日连续清理与一键批量提交**:
   - 标记当日“已整理”后可继续切往 `8月13日` 等任意日期，待删项持续累积在**全局待删暂存篮**中。
   - 点击【提交清理】，触发 1 次系统删除确认将废片移入“最近删除”；若本次删除照片导致某些用户相簿变空，随即自动触发空相簿（及空文件夹）即刻删除。

## 3. 功能需求规格 (Functional Requirements)

### 3.1 图库接入与权限引导 (FR-1: PhotoKit Authorization & Library Scope)
- **FR-1.1 系统图库接入**: 通过 `PHPhotoLibrary.shared()` 接入 macOS 当前设定的“系统照片图库”。
- **FR-1.2 权限状态引导**:
  - 首次启动请求 `.readWrite` 完整照片访问权限；
  - 若用户拒绝或仅授予受限权限（Limited），展示清晰的权限引导页并提供一键跳转【系统设置 -> 隐私与安全性 -> 照片】按钮。
- **FR-1.3 实时图库变更监听**: 注册 `PHPhotoLibraryChangeObserver`，当系统相册发生资产增删、收藏变更或相簿结构变更时，应用内网格、相簿归属面板、计数与暂存篮状态实时自动同步。
- **FR-1.4 隐藏相簿隐私策略**:
  - 默认排除原生“已隐藏 (Hidden)”相簿中的资产（`includeHiddenAssets = false`）；
  - 在【设置 (`⌘,`)】中提供“包含已隐藏照片”开关（默认关闭），手动开启后方可纳入索引与展示。
- **FR-1.5 iCloud 优化存储兼容**:
  - 网格缩略图加载与相似图特征提取**严格仅使用本地可用缩略图/中等预览图**，禁止在列表浏览或后台分析时静默触发大批量 iCloud 原图下载；
  - 当资产原片仅存于 iCloud 时，缩略图显示云端角标；仅当用户主动进入该资产的大图快审、同屏高清对比或点击播放视频时，允许通过网络流式拉取高清资源（`isNetworkAccessAllowed = true`）并显示环形加载进度。

### 3.2 366 天日历面板与增量进度管理 (FR-2: 366-Day Slice & Progress Engine)
- **FR-2.1 默认定位与任意跳转**:
  - 每次冷启动默认选中系统当前日期对应的“月-日”（如 `11-11`）；
  - 左侧常驻（可折叠）全年 **12 个月 / 366 天（固定包含 `02-29` 闰日）** 导航面板，支持点击任意月-日（如 `08-13`）即时切换，同时提供顶部日期快速选择器与【回到今天】、【下一个待整理日】快捷按钮。
- **FR-2.2 日期归属口径**:
  - 按系统当前日历时区（`Calendar.current`）提取 `PHAsset.creationDate` 的 `month` 与 `day`，聚合所有年份同月同日的照片、Live Photo 与视频。
- **FR-2.3 四态进度定义**:
  每个月-日切片根据当前图库资产集合 $A_{\text{current}}$ 与本地持久化的“已审资产 ID 集合” $S_{\text{reviewed}}$ 自动计算状态：
  1. **空置 (`empty`)**: $A_{\text{current}} = \emptyset$（历年该日无任何照片/视频，日历格置灰，跳转“下一待整理日”时自动跳过）；
  2. **待整理 (`pending`)**: $A_{\text{current}} \neq \emptyset$ 且该日期从未被标记完成（$S_{\text{reviewed}} = \emptyset$）；
  3. **已整理 (`completed`)**: $A_{\text{current}} \neq \emptyset$ 且 $A_{\text{current}} \subseteq S_{\text{reviewed}}$（当前该日所有存量资产均在已审集合内，日历格显示绿色完成标识）；
  4. **有新增待审 (`hasNew`)**: 该日期曾标记完成（$S_{\text{reviewed}} \neq \emptyset$），但存在新增未审资产 $A_{\text{new}} = A_{\text{current}} \setminus S_{\text{reviewed}} \neq \emptyset$（如明年今日拍了新照，或从相机补导了往年该日照片；日历格显示橙色新增标识）。
- **FR-2.4 完成态触发与重置**:
  - 用户点击当前日期工具栏的【完成当日整理】按钮时，将当前日期下所有未处于“待删暂存篮”中的存量资产 `localIdentifier` 并入 $S_{\text{reviewed}}$；
  - 支持对已整理日期点击【重置为未整理】（清空该日的 $S_{\text{reviewed}}$）。
- **FR-2.5 全局清理统计看板**:
  - 侧栏顶部展示：`已整理天数 / 有照片总天数` 进度条、`累计清理照片/视频数`、`累计释放空间 (MB/GB)`。

### 3.3 年份分组网格与多维筛选 (FR-3: Year-Grouped Grid & Filters)
- **FR-3.1 按年份倒序分组**:
  - 主视图将选中月-日的资产按年份**倒序**（如 `2026年8月13日` → `2025年8月13日` → `2020年8月13日`）分组展示，组头显示具体日期、星期、当年张数及【全选本年未收藏项】快捷操作；
  - 同一年份内按拍摄时间升序排列。
- **FR-3.2 缩略图信息角标**:
  - 清晰标注：视频时长（如 `01:24`）、Live Photo 实况图标、截屏标识、收藏红心 `❤️`、已归属相簿计数小标签（如 `📁 2`）、单文件体积（当 `> 20MB` 或开启体积显示时）、`新增未审` 角标（当日期处于 `hasNew` 状态时）、`已在待删篮` 半透明红色遮罩与删除图标。
- **FR-3.3 顶部快捷过滤栏**:
  - 支持过滤当前月-日资产：
    - `全部 (N)`
    - `仅照片` / `仅视频`
    - `仅截屏与录屏`
    - `大体积 (>20MB)`（支持按体积降序检视）
    - `相似/连拍组`
    - `未入任何相簿`（快速找出尚未分类到任何用户相簿的散落照片）
    - `仅看新增`（仅在日期状态为 `hasNew` 时显示）
- **FR-3.4 多选与框选交互**:
  - 支持单击选中、`Shift + 单击` 区间连选、`⌘ + 单击` 增减多选、鼠标拖拽橡皮筋框选，选中后可批量加入/移出待删暂存篮，或批量调整右侧相簿归属。

### 3.4 大图快审流与原生相册联动 (FR-4: Quick Review & Native Sync)
- **FR-4.1 无缝进入与退出**:
  - 在网格选中任意资产按 `Space`（或双击缩略图）立即进入大图快审视图；再次按 `Space` 或 `Esc` 返回网格并保持焦点定位在当前最后审阅的资产上。
- **FR-4.2 原生媒体高保真播放**:
  - **静态图 / RAW**: 高清缩放查看（支持触控板双指缩放、双击 100% 放大与拖拽平移）；
  - **Live Photo**: 使用原生 `PHLivePhotoView` 渲染，支持悬停或快捷键 `L` 播放实况动态与声音；
  - **视频**: 使用原生 `AVPlayerView` 流式播放（支持 HDR、慢动作帧率还原、进度条拖拽与静音/有声切换）。
- **FR-4.3 EXIF 详情与右侧检视栏**:
  - 右侧检视栏（快捷键 `I` 显隐）包含上下两部分或分段标签：**【相簿归属】** 与 **【EXIF 元数据】**（文件名、精确拍摄时间、文件大小、像素分辨率、格式、相机/手机型号与镜头参数、拍摄地点名称）。
- **FR-4.4 同步原生“收藏 ❤️”**:
  - 按快捷键 `F`（或点击红心按钮）直接通过 `PHAssetChangeRequest` 修改系统相册中该资产的 `isFavorite` 属性（无需系统确认弹窗，即时双向同步）。
- **FR-4.5 全键盘极速审阅流**:
  - `←` / `→`：上一张 / 下一张（底部胶片条同步滚动并预加载前后高清图）；
  - `Delete` / `Backspace` / `X`：切换当前资产“加入待删暂存篮 / 从待删暂存篮移出”（默认标记待删后自动跳至下一张，可在设置关闭）；
  - `⌘Z`：撤销最近一次加入/移出待删篮操作。

### 3.5 当日相似/连拍识别与同屏对比挑片 (FR-5: Per-Day Similarity & Compare View)
- **FR-5.1 按需单日轻量聚类**:
  - 当用户切换到某个月-日时，后台异步提取当天照片的本地缩略图：
    1. 优先合并原生连拍簇（相同 `burstIdentifier`）；
    2. 对同一年份当日照片运行 macOS 原生 `Vision` 框架 `VNGenerateImageFeaturePrintRequest` 计算特征距离，将高度相似的 2 张及以上照片归为一个“相似组 (Similarity Group)”。
- **FR-5.2 网格平铺不折叠展示**:
  - 网格内**严格保持原有时间顺序平铺，绝不折叠隐藏任何照片**；
  - 属于同一相似组的缩略图使用统一的分组视觉外框标识，并在该组首张上方显示轻量操作胶囊：【相似组 · N 张 | 对比此组】。
- **FR-5.3 同屏并排对比视图 (Compare View)**:
  - 点击【对比此组】（或在选中多张任意照片后按快捷键 `C` 发起对比），进入同屏多图对比界面；
  - 支持**同步缩放与同步平移 (Synced Zoom & Pan)**；
  - 勾选本组要保留的 1~N 张最佳照片后，点击【保留已选，其余移入待删篮】一键淘汰同组其余废片（自动遵守收藏 ❤️ 保护规则）。

### 3.6 相簿归属管理与空相簿/空文件夹即时自动清理 (FR-8 / Core Album Feature)
*(注：为保持核心链路连贯，此处定义完整的相簿归属与自动清零规范)*
- **FR-6.1 可管理相簿范围**:
  - 纳入管理的相簿为用户自建的**普通相簿**（`PHAssetCollectionType.album`，subtype `.albumRegular`，且 `canPerform(.addContent)` / `canPerform(.removeContent)` 为真），完整解析并展示其所在的相簿文件夹层级路径（如 `家庭 / 宝宝成长`）；
  - 系统内置智能相簿（如“最近项目”、“视频”、“实况照片”）、只读智能相簿及共享相簿不混入手动归属调整列表，避免无效写入报错。
- **FR-6.2 “所属相簿”与“未加入相簿”双区展示（支持单选与多选）**:
  - 当在网格或大图快审中选中 **1 张**照片/影片时，右侧相簿面板实时切分为两个明确区块：
    1. **【所属相簿 (M)】**: 列出当前资产已归属的所有普通相簿（带 `[✓]` 勾选态，显示相簿层级路径与相簿内照片总数）；点击取消勾选即刻调用 `removeAssets` 将该资产从对应相簿移出。
    2. **【未加入相簿 (K)】**: 列出当前资产尚未归属的所有其他普通相簿（带 `[ ]` 未勾选态）；点击勾选即刻调用 `addAssets` 将该资产加入对应相簿（PhotoKit 增删普通相簿成员均**无系统弹窗**，毫秒级生效）。
  - 当在网格中多选 **N 张 ($N \ge 2$)** 照片/影片时，支持批量三态展示与调整：
    - **【所属相簿】** 置顶展示：**全部选中项均属于**的相簿 `[✓]`（点击则全部移出），以及**部分选中项属于**的相簿 `[-]`（点击第一次将全部选中项补齐加入该相簿 `[✓]`，再点击则全部移出 `[ ]`）；
    - **【未加入相簿】** 展示：**所有选中项均不属于**的相簿 `[ ]`（点击则将全部选中项批量加入该相簿）。
- **FR-6.3 相簿搜索过滤与一键“新建相簿并加入”**:
  - 面板顶部配备实时搜索框（支持按相簿名或上级文件夹名模糊匹配过滤）；
  - 提供【+ 新建相簿并加入】快捷入口（若搜索框输入的名称不存在，也可直接回车一键创建该名称相簿）：在同一个 `PHPhotoLibrary.performChanges` 原子事务内完成“新建相簿（可选指定上级相簿文件夹）+ 将当前选中照片/影片加入该相簿”，确保新建瞬间即非空。
- **FR-6.4 空相簿与空上级文件夹即刻自动清理**:
  - **清理范围**: 包含所有资产数量为 `0` 的用户普通相簿（`PHAssetCollection` subtype `.albumRegular`），以及内部既无任何子相簿也无任何非空子文件夹的**空用户相簿文件夹**（`PHCollectionList` subtype `.regularFolder`）。
  - **即刻触发时机**:
    1. **应用启动完成图库索引时**: 自动全量扫描一次历史遗留的空普通相簿与空相簿文件夹，若存在则立即发起删除；
    2. **在本应用内将照片移出某相簿后**: 若该相簿成员数变为 `0`，立即触发清理；
    3. **在本应用内提交“待删暂存篮”成功删除照片后**: 重新校验受影响的用户相簿，凡成员数变为 `0` 的相簿立即合并触发清理。
    *(安全防冲突保护：对于外部 Photos.app 触发的 `photoLibraryDidChange` 事件，仅更新界面计数而不盲目抢删外部刚新建的空相簿，防止用户在原生相册刚点“新建相簿”尚未拖入照片的瞬间被误删)*。
  - **自底向上级联清理逻辑**:
    - 当删除一个或多个空相簿后，立即自底向上检查其所属父级 `PHCollectionList` 文件夹；若父文件夹内已无任何剩余相簿或子文件夹，紧接着调用 `PHCollectionListChangeRequest.deleteCollectionLists` 连带删除空文件夹（直至顶层）；
    - 提示说明：受 macOS PhotoKit 安全机制约束，删除相簿/文件夹会触发系统原生确认框，应用在同一触发批次内会将所有待删空相簿合并至单次请求提交，最小化确认次数。

### 3.7 双重安全防误删与全局待删暂存篮 (FR-7: Favorite Lock & Global Trash Basket)
- **FR-7.1 收藏 ❤️ 免弹窗锁定保护**:
  - 凡 `isFavorite == true` 的资产，默认处于**删除锁定保护状态**；
  - 无论在大图单删、网格多选批删，还是相似组“其余移入待删篮”中，系统均**自动跳过所有已收藏资产**，仅弹出非阻塞轻提示（Toast）：*“已自动跳过 N 张收藏 ❤️ 照片；如需删除请先按 F 取消收藏”*；
  - 若用户在某资产已被放入待删暂存篮后又对其点亮了“收藏 ❤️”，该资产自动从待删暂存篮移出。
- **FR-7.2 全局跨日期暂存篮与本地持久化**:
  - 底部/侧边常驻【待删暂存篮】栏，实时显示当前暂存总项数与预计释放空间（如 `待删 24 项 · 预计释放 1.86 GB`）；
  - 支持展开抽屉按日期检视所有待删缩略图、单张恢复或一键清空暂存篮；
  - 暂存篮内的 `localIdentifier` 列表每次变动即时写入本地持久化文件，支持跨日期连续累积与跨重启恢复。
- **FR-7.3 一键批量提交系统删除**:
  - 点击【提交清理 (N 项)】时，汇总暂存篮内全部有效资产一次性调用 `PHAssetChangeRequest.deleteAssets`；
  - 用户在弹出的 **1 次** macOS 系统确认框中确认后：
    1. 照片/视频安全移入 Apple 原生相册“最近删除”（享有 30 天恢复期）；
    2. 清空暂存篮并累加历史释放空间统计；
    3. 自动衔接执行 **FR-6.4** 检测因本次删照而变空的相簿并即刻清理。
- **FR-7.4 退出前未提交提醒**:
  - 当待删暂存篮非空且用户关闭窗口或退出应用时，弹出三选一提示：【立即提交清理并退出】、【保留暂存篮，下次继续】、【取消】。

### 3.8 应用生命周期与偏好设置 (FR-8: App Lifecycle & Preferences)
- **FR-8.1 纯按需桌面窗口形态**:
  - 标准 macOS 桌面应用（显示在 Dock），关闭主窗口即彻底终止进程（`applicationShouldTerminateAfterLastWindowClosed = true`），**无后台常驻进程、无菜单栏驻留、无通知打扰**。
- **FR-8.2 偏好设置 (`⌘,`)**:
  - 是否包含“已隐藏”相簿照片（默认：否）；
  - 是否启用“自动即刻删除空相簿与空文件夹”（默认：开启，可手动关闭）；
  - 大图快审标记待删后是否自动跳至下一张（默认：是）；
  - 相似图识别灵敏度（标准 / 严格 / 关闭自动识别）；
  - 重置统计数据或清空所有“已整理”进度记录（需二次确认）。

## 4. 非功能需求 (Non-Functional Requirements)

1. **性能与响应指标**:
   - **启动索引耗时**: 在包含 50,000 ~ 100,000 张资产及 200 个用户相簿的 Apple Silicon Mac 上，冷启动构建 366 天日期映射索引与反向相簿归属映射耗时 **≤ 500ms**；切换选中照片刷新“所属/未加入相簿”耗时 **≤ 5ms（纯内存查表）**。
   - **网格帧率与内存**: 采用 `PHCachingImageManager` 滑动窗口预热与释放，年份分组网格滚动保持 **60/120fps**；常规浏览常驻内存控制在 **250MB 以内**。
   - **单日相似图聚类耗时**: 对单日 100 张照片基于本地缩略图执行 `Vision` 特征提取与聚类耗时 **≤ 1.5s**，全程在后台并发队列执行，不阻塞 UI。
2. **数据安全与隐私**:
   - **100% 纯离线端侧运行**: 零外部服务器请求，不收集任何遥测数据。
   - **100% 官方 PhotoKit 合规操作**: 严禁直接篡改系统相册底层私有 `Photos.sqlite` 文件，一切读取、收藏同步、相簿成员调整、空相簿/文件夹删除与照片删除均通过官方 `PhotoKit` API 执行，确保 iCloud 照片图库同步绝对安全一致。

---

## 5. 明确不做的边界 (Non-Goals — MVP 阶段)

1. **不做全库一次性重复图大扫描**: 只针对当前选中的“月-日”切片做即时轻量相似分析。
2. **不做图像编辑与调色修图**: 不提供裁剪、滤镜、曝光调整功能。
3. **不操作系统内置智能相簿与共享相簿成员**: 智能相簿（Smart Albums）由规则决定无法手动增删成员，iCloud 共享相簿涉及多人协作，均不纳入右侧手动归属调整与空相簿自动删除范围。
4. **不与外部 NAS 目录做比对导入**: NAS 文件级归档由独立的 `Photo Album` 项目负责。
5. **不做后台常驻、菜单栏小组件与定时弹窗提醒**。

## 6. 验收标准清单 (Acceptance Criteria)

- [ ] **AC-1 (今日默认与 366 日历)**: 启动应用默认展示当天月-日的跨年份照片；366 天面板（含 `02-29`）准确区分“空置、待整理、已整理、有新增待审”四种状态。
- [ ] **AC-2 (增量新增检测)**: 将 `08-13` 标记为“已整理”后，向系统相册新增一张拍摄日期为任意年份 `08-13` 的照片，应用内 `08-13` 自动变为“有新增待审”且该照片带“新增”角标。
- [ ] **AC-3 (三视图闭环)**: 年份倒序网格、空格大图快审（含 Live Photo、视频、EXIF、`F` 键收藏同步）、当日相似组平铺框选与同屏同步缩放对比挑片均流畅可用。
- [ ] **AC-4 (相簿归属双向调整与新建)**: 单选或多选照片/影片时，右侧准确分组列出【所属相簿】与【未加入相簿】（含三态与搜索过滤），点击勾选/取消即时同步至系统相册，且支持面板内一键新建相簿并自动归入选中项。
- [ ] **AC-5 (空相簿与空文件夹即刻自动删除)**: 启动时若存在空普通相簿/空文件夹即触发删除；当把某相簿内最后一张照片移出，或通过暂存篮提交删除导致某相簿变空时，立即自动触发删除该空相簿，若其父级相簿文件夹也随之变空则连带删除空文件夹。
- [ ] **AC-6 (收藏防误删保护)**: 对带 `❤️` 收藏的照片执行单删、框选删除或相似组“删除其余”时，均被免弹窗拦截跳过并弹出轻提示；取消收藏后可正常加入待删篮。
- [ ] **AC-7 (全局暂存篮与单次确认)**: 跨多个月-日标记待删照片后，点击一次【提交清理】，照片删除仅弹出 1 次系统确认框并移入“最近删除”，释放空间统计准确累加。
- [ ] **AC-8 (iCloud 安全与零常驻退出)**: 开启“优化 Mac 储存空间”时浏览与算相似度不触发原图批量下载；关闭主窗口后进程彻底退出无残留。
