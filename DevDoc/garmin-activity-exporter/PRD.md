# 产品需求文档 (PRD) - Garmin Activity Exporter (v1)

## 1. 产品概述 (Overview)

打造一款 **macOS 原生桌面应用（Swift + SwiftUI）**，基于官方 **Garmin Connect Personal API**，帮助用户查看指定起始日期以来的个人运动记录（Activity），按实际存在的运动类型多选过滤，并支持勾选单个或多个活动下载（以及在同运动类型下合并为一个文件下载）。

> **范围约束**：严格限定于本文档列出的第一版（v1）需求，不添加任何未提及的扩展功能（如增量同步比对库、复杂统计图表、结束日期选择器、关键词搜索等）。

---

## 2. 功能需求规格 (Functional Requirements)

### 2.1 认证与区域自动识别 (Authentication & Auto Region Detection)
- **FR-1.1 Personal API Key 输入与自动打开获取页面**：
  - 首次启动（无已保存凭据）或点击「更换/退出 Key」进入登录界面时，显示简洁的 API Key 输入界面，并**自动在系统默认浏览器中打开 Garmin Connect 获取 Personal API Key 的页面**（默认打开国际区 `https://connect.garmin.com/app/settings/personalApiToken`；若上次登录过中国区则自动打开 `https://connect.garmin.cn/app/settings/personalApiToken`，同时在登录页底部附带双区获取页面的快捷链接）。
- **FR-1.2 国际区/中国区自动探测**：
  - 界面**不设手动区域选择框**。
  - 用户提交 API Key 后，应用自动向官方两个区域的 Token 换取接口发起探测请求：
    - 国际区：`https://personal.connectapi.garmin.com/personalapitoken-service/personal-api/personal-api-key/token`
    - 中国区：`https://personal.connectapi.garmin.cn/personalapitoken-service/personal-api/personal-api-key/token`
  - 根据返回 `200 OK` 的端点自动锁定该 Key 所属区域（Base URL）及换取到的 JWT `Bearer Token`（有效期 24 小时）。若两个端点均返回 `401/403`，则提示 API Key 无效或已过期。
- **FR-1.3 凭据安全持久化与自动登录**：
  - 验证成功后，将 `Personal API Key` 与探测到的区域标识安全保存至 **macOS Keychain**。
  - 后续启动应用时，自动从 Keychain 读取 API Key 并静默获取/复用有效 Bearer Token 直接进入主界面。
  - 主界面提供**「更换/退出 Key」**按钮，方便用户在 Key 过期或更换账号时清除并重新输入。

### 2.2 活动列表与筛选 (Activity List & Filtering)
- **FR-2.1 起始日期选择（日历控件）**：
  - 界面顶部提供**单个「起始日期」日历控件**（不设结束日期）。
  - 日历可选日期下限为 **`2000-01-01`**，上限为**当天**。
  - **每次打开软件时，起始日期默认固定为当天**（不记忆上一次关闭时的日期）。
  - 当起始日期变更时，调用 Garmin Personal API 拉取从该起始日期（含当天，`YYYY-MM-DD`）起至今的所有 Activity。
- **FR-2.2 运动类型筛选（多选下拉框）**：
  - 提供**运动类型多选下拉框（Dropdown + 复选框）**。
  - **动态选项规则**：下拉框内**仅显示当前选定起始日期范围内实际存在的运动类型**（从当前拉取回来的活动列表中动态提取去重，不存在的类型不展示）。
  - **默认与交互**：每次按起始日期拉取完成后，类型筛选默认处于**全选（显示全部）**状态；用户勾选或取消勾选任意类型时，列表即时过滤显示所选类型的活动。
- **FR-2.3 Activity 列表字段展示**：
  - 列表每行左侧提供复选框（支持勾选一个或多个活动），并展示以下 **5 项基础信息**：
    1. **名称 (`activityName`)**：活动标题。
    2. **日期/时间 (`startTimeLocal`)**：活动本地开始时间（如 `YYYY-MM-DD HH:mm`）。
    3. **类型 (`activityType.typeKey`)**：运动类型。
    4. **距离 (`distance`)**：活动距离（格式化为 `km` 或 `m`）。
    5. **时长 (`duration`)**：活动时长（格式化为 `HH:mm:ss` 或 `mm:ss`）。

### 2.3 活动下载与同类型合并 (Download & Same-Type Merge)
- **FR-3.1 导出格式支持**：
  - 支持选择导出格式：**`GPX (.gpx)`**、**`TCX (.tcx)`**、**`FIT (.fit)`**。
  - Garmin Personal API 原始下载接口（`GET /download-service/files/activity/{activityId}`）返回包含原始 `.fit` 文件的 ZIP 压缩包：
    - 选择 `FIT` 时：解压提取 `.fit`（合并时生成合并后的 `.fit`）。
    - 选择 `GPX` 或 `TCX` 时：解析 `.fit` 文件并转换为标准 `.gpx` 或 `.tcx` 文件。
  - **无 GPS 轨迹活动的处理**：因为 GPX 标准要求每个轨迹点 `<trkpt>` 必须具备经纬度（`lat`/`lon`），当所选活动不含 GPS 坐标（如室内跑、骑行台、力量训练等）且用户选择了 `GPX` 格式时，明确提示用户并支持一键回退/切换为 `TCX` 或 `FIT` 格式保存，防止丢失心率、踏频、时间序列等数据。
- **FR-3.2 勾选下载与同类型合并控制**：
  - 用户可勾选 **1 个或多个** Activity 进行下载。
  - **合并选项显隐/启用条件**：
    - 当勾选数量 `>= 2` **且所有勾选 Activity 的运动类型（`typeKey`）完全相同时**，界面提供「合并」勾选项（或「合并下载」操作）。
    - 当仅勾选 1 个活动，或勾选的多个活动包含不同运动类型时，**不提供/禁用「合并」选项**。
  - **下载输出行为**：
    - **不合并（单选或多选逐个下载）**：为每个勾选的 Activity 分别生成对应的独立文件。
    - **开启合并（多选同类型活动）**：按各活动的开始时间（UTC 时间戳）**升序排列拼接**轨迹点与分段（Lap）数据，**最终仅生成 1 个合并后的文件**。
- **FR-3.3 保存目录与文件命名规则**：
  - **保存目录**：界面展示当前保存目录路径（默认 `~/Downloads`），支持点击按钮调用 macOS 原生文件夹选择器（`NSOpenPanel`）更改目录并持久化记住该路径；点击下载时直接平铺写入该目录，不创建任何子目录。
  - **文件命名格式**：
    - 单文件：`{YYYY-MM-DD}_{类型}_{名称}_{activityId}.{ext}`
    - 合并文件：`{最早日期}_至_{最晚日期}_{类型}_合并({N}条).{ext}`
    - 自动过滤文件名中的系统非法字符（如 `/`、`:` 等替换为 `_`）。

## 3. 验收标准 (Acceptance Criteria)

1. **自动识别区域登录**：输入国际区或中国区的 Personal API Key，无需手动选择区域即可自动探测成功并保存至 Keychain；重启应用自动保持登录态。
2. **日历默认与范围**：每次冷启动应用，起始日期日历均默认指向当天；最早可向前选择至 `2000-01-01`，无结束日期控件。
3. **动态类型多选**：切换起始日期后，类型多选下拉框仅列出当前时间段内有记录的运动类型；勾选/取消类型能实时过滤列表。
4. **列表 5 要素**：列表清晰展示「名称」、「日期/时间」、「类型」、「距离」、「时长」5 列及勾选框。
5. **条件合并与下载**：
   - 勾选 2 条同为 `running` 的活动时，出现「合并」选项；开启合并下载后，在目标目录下仅生成 1 个按时间先后拼接的合并文件。
   - 勾选 1 条 `running` + 1 条 `cycling` 时，不提供「合并」选项，仅支持各自独立下载。
   - 选择无 GPS 室内活动导出 GPX 时有明确提示或回退机制。
