# Vibe Coding 实施路线图 (IMPLEMENTATION PLAN) - M5Track-M9N

本路线图专为 **Antigravity AI 编程助手** 进行逐步、原子化开发而设计。
每个阶段包含清晰的目标、修改的文件、原子化任务清单与**确定的验证命令与检查点**。

---

## 阶段概览 (Phases Overview)

- **Phase 1**：PlatformIO 项目基建、M5Unified 初始化与 Type-C 底部朝向屏幕验证
- **Phase 2**：NEO-M9N 串口驱动与 UBX-NAV-PVT / SIG 数据解算引擎
- **Phase 3**：双源时钟引擎 (NTP ⇋ GPS ⇋ RTC 闭环) 与 u-blox AGPS 星历注入
- **Phase 4**：MicroSD 卡挂载与流式 GPX 增量写盘服务
- **Phase 5**：AXP192 车载电源监视与 10 秒断电安全关机倒计时
- **Phase 6**：Wi-Fi 管理器、Web Captive Portal 配网与多 SSID NVS 增删
- **Phase 7**：全黑主题 UI、手势滑动机、初始化页与正式 4 页面开发
- **Phase 8**：多任务全链路集成、系统联调与压力稳定性测试

## Phase 2: NEO-M9N 串口驱动、车载工况调优与气压高程融合 (GNSS & Baro-Fusion)

### 目标
在独立 Core 0 任务中驱动 Port.C 串口与板载 BMP280 气压计，注入车载专用调优参数（车载模式、静止死区锁、四星并发），实现气压-GNSS 高程互补滤波融合算法。

### 原子任务清单
- [ ] **Task 2.1**：创建 `src/model/SystemState.h`，定义 `GnssData`、`SatInfo` 及互斥锁 `SemaphoreHandle_t`。
- [ ] **Task 2.2**：实现 `src/driver/GnssDriver.h/.cpp`，初始化 `Serial2.begin(38400, SERIAL_8N1, 13, 14)`，下发 UBX 命令切换模组波特率至 115200 bps 并重新握手。
- [ ] **Task 2.3**：配置 NEO-M9N 仅输出 UBX 二进制协议（关闭 NMEA），开启 5Hz 导航解算频度。
- [ ] **Task 2.4**：实现车内工况专项固件调优：
  - 动态平台切换为 `DYN_MODEL_AUTOMOTIVE`（车载模式）；
  - 设置 `setStaticHoldThreshold(50)`（0.5 m/s 静态门限，杜绝等红灯慢漂）；
  - 设置卫星最低仰角掩码为 $12^\circ$，载噪比门限为 $24\text{ dBHz}$；
  - 开启 RAIM 完好性监测与多径抗扰抑制；
  - 增加动力学合理性抗跳变离群滤波 (Kinematic Plausibility Filter)：剔除 1 秒内速度突变 $>180\text{km/h}$ 或加速度 $>1.2\text{G}$ 的粗大多径飞点；
  - 锁定使能 BDS + GPS + GLO + GAL 四星并发。
- [ ] **Task 2.5**：开发 `src/driver/BaroDriver.h/.cpp`，通过硬件 I2C（地址 `0x76`）初始化模块板载 BMP280 传感器，实现 10Hz 超高分辨率气压与温度采样。
- [ ] **Task 2.6**：开发 `src/service/AltitudeFusion.h/.cpp`，实现高程互补滤波算法：以 GPS 3D 高度动态修正海平面基准气压 $P_0$，以气压高频相对位移滤波生成平滑融合高程。
- [ ] **Task 2.7**：开发 `src/service/DeadReckoningService.h/.cpp`：
  - 监听 GNSS 信号状态，当 3D Fix 跌落至 No Fix 时无缝切入推算模式；
  - 调用 `M5.Imu` 读取 6 轴传感器陀螺仪 Z 轴（Yaw 角速度 $\omega_z$），高频（50Hz）积分推算实时车辆偏航角；
  - 结合失锁前 3 秒平滑平均速度及纵向加速度进行平面位移几何递推；
  - 持续融合 BMP280 气压高度，并实现出盲区后 2 秒卡尔曼低通平滑恢复。
- [ ] **Task 2.8**：开发 `src/service/TunnelService.h/.cpp` 与 `src/service/TunnelDb.h`：
  - 片上存储与内存化：从板载 Flash `LittleFS` (`/littlefs/tunnels.bin`) 读取并在 2ms 内载入 8MB PSRAM 内存缓存，严禁读取 TF 卡；
  - 兜底保障：若 LittleFS 无文件则自动降级使用代码常驻 `TunnelDb.h` (PROGMEM) 出厂版本；
  - 实现入口 200m 空间哈夫曼距离与入口航向自动匹配触发；
  - 进入特长隧道后，将 DR 轨迹完全锁死在真实单维矢量轴线上，彻底消除 15~20 分钟超长盲区的横向零漂。
- [ ] **Task 2.9**：实现射频抗干扰与天线回路诊断：
  - 周期性（每 2 秒）轮询 `UBX-MON-RF`，解析 `jamFlags` 干扰严重度、`antStatus` 开路/短路状态及底噪；
  - 注入 `GnssData` 供 UI 告警展示。
- [ ] **Task 2.10**：实现 FreeRTOS 任务 `gnssTask`，循环读取 `myGNSS.checkUblox()` 与气压计，输出经纬度、车速、航向角、融合海拔、四星状态、DR 推测与射频状态标记。

### 验收与验证指令
- **车载工况与高程融合检查**：
  1. 打开串口监视器：
     ```bash
     pio device monitor -b 115200
     ```
     *预期输出*：每 200ms 打印一次：`[GNSS] Fix: 3D, Sats: 21 (BDS:9, GPS:7, GLO:4, GAL:1), Speed: 0.0 km/h, BaroAlt: 128.4m, FusionAlt: 128.5m, Temp: 24.2C`。
  2. **静止死区验证**：静止放置 5 分钟，车速绝对稳定在 `0.0 km/h`，经纬度坐标与里程完全锁死不跳动。
  3. **气压响应验证**：垂直移动设备 1 米（如手举起），融合海拔即刻高灵敏度响应变化约 1.0m，无 GPS 白噪声突变。
  4. **盲区惯导推算验证**：进入信号屏蔽区（拔掉或遮蔽天线），串口输出自动切换为 `[DR Mode] Yaw: 182.4 deg, Speed: 62.0 km/h, Elapsed: 8s`；手持设备旋转转弯，航向角实时随动偏转，海拔随电梯/坡道平滑变化。恢复天线后，平滑收敛回归卫星定位。
  5. **特长隧道自动吸附验证**：模拟注入天山胜利隧道入口坐标与南向航向，系统在 1 秒内自动输出 `[Tunnel] Auto-engaged: 天山胜利隧道 (22.1km)`，切入单维轴线锁死模式，横向零漂强制为 0。

## Phase 4: MicroSD 卡流式 GPX 记录、长文件名与机内格式化 (Track Logger & SdFat)

### 目标
基于 `SdFat` 驱动实现标准 `.gpx` 格式的增量写盘服务，原生支持长文件名 (LFN)，实现 TF 卡格式不兼容自动弹窗提示与机内一键 FAT32 格式化。

### 原子任务清单
- [ ] **Task 4.1**：创建 `src/service/TrackLogger.h/.cpp`，基于 `SdFat` 显式绑定 Core2 硬件 SPI（SCK: 18, MISO: 38, MOSI: 23, CS: 4），开启长文件名 (LFN) 支持；实现轻量级 WGS-84 转 GCJ-02 坐标加密算法及境外边界判定。
- [ ] **Task 4.2**：实现格式检测、机内格式化与安全容量维护 `SdDriver::checkAndFormat()`：
  - 格式不兼容检测：挂载失败或非 FAT32 格式时向 UI 抛出 `EVT_SD_INCOMPATIBLE`，触发居中弹窗；用户确认后调用 `sdFormatter.format()` 快速重置并自动重建 `/tracks/` 目录；
  - 空间低水位保护与自动循环清理：开机及建档前校验剩余空间，$<200\text{MB}$ 触发预警，默认自动成对清理最古老的 `W-` 与 `C-` 历史轨迹至恢复 $>500\text{MB}$。
- [ ] **Task 4.3**：编写双坐标系 GPX 1.1 并行落盘引擎，支持根据记录开始的本地时间命名并成对生成 `W-yyyymmdd-hhmmss.gpx`（原始 WGS-84）与 `C-yyyymmdd-hhmmss.gpx`（China 火星 GCJ-02），包含全量标准字段与 `<extensions>` 硬件指标。
- [ ] **Task 4.4**：实现动静自动启停 (严格 AND 双条件判定 - 选项 A)：
  - 触发建档：仅在 `fixType >= 3D`、`HDOP < 2.0`（高可靠卫星定位）且车速 $> 3\text{km/h}$（IMU 确认行车）同时满足时，自动成对创建新文件 `W-yyyymmdd-hhmmss.gpx` 与 `C-yyyymmdd-hhmmss.gpx` 并打入第一个真实高精度卫星点；
  - 1 小时自动切片 (方案 B)：行车持续记录满 3,600 点自动闭合当前双文件，并在下一秒（无重叠点）自动创建新分卷平滑衔接；
  - 地库出库防漂：在地库无星或原地等待时不打假点，驶出地库首获 3D Fix 瞬间建档；
  - 临时停靠防漂：静止 0~15 分钟期间智能暂停追加重复点，避免红绿灯小黑团，若 15 分钟内起步无缝继续记录；
  - 15 分钟停止记录：车速为 0 持续达 15 分钟（或断电倒计时归零）后自动追加 GPX 尾部并闭合文件，设备继续保持亮屏开机；
  - 30 分钟整机休眠：静止持续达 30 分钟无移动，切入超低功耗 Deep Sleep 关机。
- [ ] **Task 4.5**：实现实时预闭合与短周期物理刷盘：每秒写入 `<trkpt>` 节点后预先追加 `</trkseg></trk></gpx>` 尾标签并维持闭合状态，下秒写入前指针回退；每 10 点调用 `file.sync()` 同步物理扇区 FAT 表。
- [ ] **Task 4.6**：实现开机断电自愈引擎 `TrackLogger::recoverIncompleteTracks()`：开机自检遍历 `/tracks/` 最新文件，若存在非正常结尾在 5ms 内自动修补闭合，100% 挽救历史轨迹。

### 验收与验证指令
- **格式不兼容弹窗与长文件名检查**：
  1. 插入一张未格式化或 exFAT 格式的 TF 卡，开机观察屏幕：立即弹出提示“检测到 TF 卡格式不兼容，是否格式化？”；点击“确认格式化”，等待 2 秒提示格式化成功并自动挂载。
  2. 拔出 TF 卡插入电脑查看：卡内文件名为规范的 `W-20261028-090000.gpx` 与 `C-20261028-090000.gpx`，绝无 `TRACK~1.GPX` 等短文件名截断。拖入 [GPX Viewer 网站](https://gpx.studio/) 校验通过。

## Phase 5: 车载电源监视、静止 30 分钟休眠与智能起步唤醒 (Power & Motion Manager)

### 目标
利用 AXP192 监听车载供电通断（10 秒掉电防丢盘保护），结合 BMI270 陀螺仪实现无 GPS 信号下的静止 30 分钟自动 Deep Sleep，以及双阶段防抖（过滤关门/就坐噪声）车辆起步自动开机。

### 原子任务清单
- [ ] **Task 5.1**：创建 `src/driver/PowerDriver.h/.cpp`，调用官方 API `M5.Power.getVBUSVoltage() > 4000` 准确感知外部 5V USB 车载供电通断；监听 AXP192 内部温度，实现 $>55^\circ\text{C}$ 暴晒暂停电池充电与 $<45^\circ\text{C}$ 恢复充电保护。
- [ ] **Task 5.2**：实现地库零 GPS 信号下的静止超时检测：读取 BMI270 3 轴加速度与角速度方差，连续 30 分钟（1800s）低于静止底噪阈值 $\text{Var} < 0.005\text{ m/s}^2$ 时，向系统抛出 `EVT_STANDSTILL_TIMEOUT`。
- [ ] **Task 5.3**：实现安全休眠与 NVS 落盘：静止超时后通知 `TrackLogger` 闭合 GPX 文件，将最后坐标/海拔写入 NVS，配置 BMI270 Any-Motion 硬件中断唤醒引脚，调用 `esp_deep_sleep_start()`（休眠电流 $<35\mu\text{A}$，由底座 500mAh 电池守护数月）。
- [ ] **Task 5.4**：实现双阶段智能防抖唤醒流水线（Two-Stage Anti-Noise Wakeup）：
  - 硬件微动触发后进入 `STATE_SILENT_ASSESS`（保持屏幕纯黑不点亮，不启动外设）；
  - 启动 3 秒评估确认窗：若为单次孤立脉冲（关车门/拿放东西/人员就坐晃动，持续 $<0.5$s 且角速度积分 $\int |\omega_z| dt \approx 0$），立即退回 Deep Sleep；
  - 若检测到持续推背加速度（$>1.5$s）与连续路面微振动能量，判定车辆起步，点亮屏幕并恢复定位记录。

### 验收与验证指令
- **静止休眠与抗干扰开机验证**：
  1. **无 GPS 静止休眠**：在地下车库断开天线静止测试，30 分钟后系统自动保存 GPX 并进入 Deep Sleep，屏幕熄灭。
  2. **机械噪声过滤**：设备休眠后，用力开关车门、人员在座椅晃动、后备箱放置行李，屏幕保持完全纯黑，0.5 秒后继续休眠，绝不误开机。
  3. **起步自动开机**：车辆点火驶出车位，设备在起步 2 秒内灵敏识别并自动开机点亮屏幕，无缝恢复轨迹记录。
