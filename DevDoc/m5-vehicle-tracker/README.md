# M5Track-Tab5 车载高精度轨迹记录仪与宽屏数字仪表盘

基于 **M5Stack Tab5**（ESP32-P4 双核 RISC-V 400MHz + ESP32-C6 Wi-Fi 6，5.0 英寸 1280×720 IPS 高清宽屏）与 **M5Stack Module GNSS (M135 / u-blox NEO-M9N)** 构建的车规级专业车载轨迹记录与宽屏多功能数字仪表系统。

系统采用 **车规宽屏左侧常驻侧边栏 (Left Dock) + 全高安全视口 (1120×720)** 架构，全面榨干 ESP32-P4 的 32MB 超大 PSRAM 算力与 720P 高清画质。原生集成板载 INA226 库仑计、快拆 NP-F550 大容量锂电池与车充宽压供电体系。

| **扩展模组：Module GNSS (M135)** | **u-blox NEO-M9N** | 四星并发高精度定位模组 | M5-Bus UART (`G38/G37` 或 `G6/G7` 自动探测) | 北斗+GPS+GLO+GAL 四星 1Hz/25Hz 高频并发定位与原子钟授时 |

| | **BMM150** | 3 轴地磁电子罗盘传感器 | BMI270(0x69) 二级 AUX I2C `0x10` | 硬件搭载；因机身贴附 MagSafe 磁吸环在软件中彻底旁路，改由 GPS+IMU 融合测向 |
| | **BMI270 (副 IMU)** | 6 轴姿态传感器 (模组板载) | 硬件 I2C (`G31/G32`) `0x69` (SDO 出厂上拉) | 与 Tab5 主板 IMU 组成双冗余互验降噪系统，均值滤波降低 30% 白噪声，单片故障 20ms 内无缝接管 |

> [!TIP]
> **I2C 物理总线零冲突与双 IMU 冗余互验架构**：
> - **双 IMU 天然正交与冗余 (Option A)**：Module GNSS (M135) 板载 BMI270 硬件 SDO 出厂上拉至高电平，物理地址天然为 `0x69`，与 Tab5 主板 `0x68` 完美正交并存。行车时双芯片 50Hz 均值滤波降噪约 30%，支持交叉互验与故障秒级热切换；停车休眠时由 Tab5 主板 `0x68` 负责 RTC 微动唤醒；
> - **MagSafe 磁干扰防护**：BMM150 (`0x10`) 彻底旁路，航向由 GPS 地面真航向与双 IMU 融合陀螺仪积分互补解算，停稳物理锁死；
> - **在线外设物理地址完全正交**：`BMI270(Master)` (`0x68`)、`BMI270(Slave)` (`0x69`)、`RX8130CE` (`0x32`)、`INA226` (`0x40`)、`BMP280` (`0x76`)，总线零地址冲突。

## 🌟 核心特性概览

- **1280 × 720 高清宽屏车载工作台**：采用 5.0 英寸 16:9 高清全贴合 IPS 屏，彻底告别原 320×240 小方屏的逼仄感。
- **左侧 160px 常驻触控侧边栏 (Left Dock)**：
  - 充分利用宽屏横向富余空间，最左侧 160px 常驻布局 6 大车载触控功能块：
    1. `🏠 仪表`：专职主页快捷键，任何页面单点秒回 Page 1；
    2. `14:35`：实时时间，点击直达 Page 7 世界时钟；
    3. `🛰️ 18`：定位状态与星数，点击直达 GPS 卫星详情；
    4. `📶 热点`：Wi-Fi 状态与 SSID，点击直达网络配网；
    5. `🔋 95%`：板载 INA226 库仑计精准电量（**有外接电源显绿色 `⚡ 95%`，无外接电源显红色 `🔋 95%`**）；
    6. `☀️ 24℃`：室外实时气象，点击直达 Page 6 天气预报；
    7. `⚙️ 工具`：专职工具箱快捷键，任何页面单点直达 Page 8。
- **1120 × 720 全高全画幅主绘制视口**：主内容区拥有 100% 垂直全高（720px），子页面拥有巨大的抗锯齿图形展现空间。
- **8 大核心仪表与自驾视图矩阵 (8-Page Driving System)**：
  - **Page 1**：核心驾驶主仪表盘（左侧 360px 大圆形罗盘 + 右侧 120pt 发光主车速与行程卡片，**长按 TRIP 卡片 2 秒全系统联动归零**）；
  - **Page 2**：海拔高度连续起伏折线图（1050px 超宽幅 1 小时连续采样 + 最高/最低极值卡片）；
  - **Page 3**：车速变化连续折线图（1050px 超宽幅采样 + 最高时速 MAX + 平均时速 AVG + 行驶/怠速工况统计，坚决不展示无意义最低时速）；
  - **Page 4**：轻量矢量自驾轨迹与返航地图（**轨迹全画幅极限自适应铺满屏幕** + 四角悬浮半透明 HUD 胶囊 + 直线距起点返航指南针）；
  - **Page 5**：车辆动态 G-Force 摩擦力圆（400px 大靶图带峰值记忆）+ 越野姿态俯仰/侧倾水平仪 + 道路真实坡度百分比（+7.5% 陡坡警告）；
  - **Page 6**：当前 GPS 坐标 12 小时两段大字气象预报（前后 12 小时一键秒切 + 温度折线 + 降水概率柱状条 + 离线长效缓存）；
  - **Page 7**：多时区世界时钟（2×2 宽幅 530×320px 大卡片，支持 GPS 经度自适应换算与大热区分类免打字点选）；
  - **Page 8**：系统动态扩展 2×2 工具箱（TF 存储管理 / Wi-Fi配网 / GPS诊断 / 硬件功耗与电量，支持多于 4 工具自动分页）。
- **纯电容屏原生手势与触控架构**：
  - 基于 Tab5 全贴合纯平触控大屏，无需任何机身外置虚拟按键；
  - 全屏左右滑动平滑切页，底部悬浮 8 颗发光小圆点（切页浮现，3 秒无操作自动彻底隐藏）。
- **全黑夜视 UI 主题 (Pure Dark Theme)**：全界面纯黑背景（`#000000`），高对比度荧光青/绿色文字指示，夜间行驶零眩光。
- **双流并行 GPX 轨迹落盘与 50% 容量硬性限额**：
  - 每秒同时流式写入 `W-yyyymmdd-hhmmss.gpx` 与 `C-yyyymmdd-hhmmss.gpx`；
  - 轨迹总占用严格限制在 **TF 卡容量的 50% 以内**，满额自动按时间倒序成对循环覆盖最旧轨迹，永不卡满；
  - 整 1 小时（3600 点）严格连续切片，合并无缝贴合；
  - XML 实时预封口、10 秒定时 `file.sync()` 与开机自动扫描未闭合标签自愈修复。
- **双 BMI270 冗余降噪与 MagSafe 强磁免疫航向**：底层彻底旁路易受干扰的地磁计，航向由 GPS 地面真航向与双 BMI270 均值融合陀螺仪（加权平均降噪 30%）高频积分，停稳锁死零漂，单芯片故障 20ms 内无缝容灾热切换，完美支持机身背贴 MagSafe 磁吸环。
- **免拔卡 Wi-Fi 高速无线导出**：
  - 工具箱内一键开启专属直连热点（`M5Track-Share`，`192.168.4.1`），手机直连浏览器秒下 GPX 轨迹，即走即关。
