# M5Track-M9N 车载高精度轨迹记录仪与仪表盘

基于 **M5Stack Core2** (ESP32) 与 **u-blox NEO-M9N** 四星高精度定位模块构建的专业级车载轨迹记录与多功能数字仪表系统。
系统采用**硬件自适应即插即用架构 (Hardware Auto-Adaptive Architecture)**：
- **阶段一（极简阶段）**：仅安装 **Core2 主机 + Module GNSS (M135)**，即可实现全部 8 大仪表与高精度轨迹记录功能。屏幕状态栏常驻电池电量显示，因尚未安装底座，电量显示为空（`🪫 0% 外部直供`）；
- **阶段二（无缝升级）**：后续随时扣上 **M5Stack Base Dual 16340 便携式电池底座 (SKU: A179)**，**无需任何二次开发或重新烧录固件**，固件自适应探测识别板载 INA226 (`0x45`) 与双 16340 电池，屏幕电池图标直接无缝亮起并显示真实电量与充放电状态。

## 🎛️ 硬件与传感器架构规范 (统一自适应架构)

系统统一支持“无底座纯线电”与“装载 Base Dual 16340 底座”两种工况，硬件各模块分工与总线地址完全统一：

| 模块层级 | 物理组件 | 搭载传感器 / 外设 | I2C 地址 / 通信引脚 | 功能用途 |
| :--- | :--- | :--- | :--- | :--- |
| **顶层：Core2 主机** | ESP32-D0WDQ6-V3 | 320x240 TFT (ILI9342C) + FT6336U 电容触控 | SPI (TFT) / I2C `0x38` (TP) | 核心计算、UI 双缓冲渲染与电容多维手势（纯平防刮玻璃面盖） |
| | AXP192 | 电源管理芯片 (PMIC) | I2C `0x34` | 车电检测、DCDC/LDO 稳压输出、电池接入状态自适应检测 |
| | BM8563 | 硬件实时时钟 (RTC) | I2C `0x51` | 板载纽扣电池独立维持断电精准走时 |
| | 振动马达 | 内部触觉振动反馈 | AXP192 LDO3 驱动 | 触摸按键触觉反馈、Page 1 里程长按 2 秒归零震动确认 |
| **中层：Module GNSS (M135)** | u-blox NEO-M9N | 四星并发高精度定位模组 | UART2 (`GPIO 13 RX2 / 14 TX2`) | BDS+GPS+GLO+GAL 四并发 1Hz/25Hz 定位与原子钟纳秒授时 |
| | **BMP280** | 高精度气压高度计传感器 | I2C `0x76` | 10Hz 气压定高，与 GNSS 互补消除垂直跳变，计算道路真实坡度 |
| | **BMI270** | 6 轴姿态传感器 (加速度计+陀螺仪) | I2C `0x68` *(标准默认地址)* | 车辆加减速推背感、过弯横向 G 值、车身俯仰/侧倾姿态与盲区 DR 惯导 |
| | **BMM150** | 3 轴地磁电子罗盘传感器 | 挂载于 BMI270 Aux I2C / `0x10` | 车身 0 航速静止时的绝对真实磁北朝向 |
| **底层扩展：Base Dual 16340**<br>*(即插即用，按需装配)* | **双 16340 电池组** | **1400mAh** 并联充电锂电池 (2×700mAh) | 内部 BAT / M-Bus 连接 | 扣上后直接提供 5~6 小时连续脱线续航，支持电芯随时拆卸更换 |
| | **INA226** | **高精度功耗/电压/电流监测芯片** | I2C `0x45` | $20\text{m}\Omega$ 精密采样，实时测量毫安级充放电电流、总线电压与即时功耗 |
| | **机械滑动电源开关** | 物理侧面滑动总电源开关 | 硬件物理隔断 | 车辆长期停放时一键物理切断电池供电，实现零漏电 |

> [!TIP]
> **I2C 物理总线零冲突**：Module GNSS 的 BMI270 独占标准地址 `0x68`，BMM150 占用 `0x10`，BMP280 占用 `0x76`；底座板载 INA226 占用 `0x45`。无论是否装配底座，I2C 总线没有任何地址重叠，驱动极其轻量健壮！

## 🌟 核心特性概览

- **320 × 240 标准横屏车载仪表盘**：界面采用 `setRotation(1)`，Type-C 供电接口位于左侧便于隐蔽走线，正面为纯平防刮玻璃电容全屏触控，右侧引出高增益外置有源天线。
- **全屏常驻电池电量与状态自适应呈现 (Battery Info Across All Screens)**：
  - 屏幕顶部 24px 状态栏（`X: 0~319, Y: 0~23`）常驻呈现电量图标与百分比：
    - **未装底座时**：电量显示为空 `🪫 0%` 或空电池框，标注外部 USB 直供，无内置电池；
    - **装上底座时**：**免二次开发自动点亮识别**，显示真实电量格与百分比（如 `🔋 85%`）；接入 USB 充电时呈现动态闪电 `⚡ 85%`。
- **全画幅 320x216 主内容安全视口**：BasePage 统一约束在 `X: 0~319, Y: 24~239`，仪表大圆盘、折线图与 4 宫格卡片视觉开阔舒展。
- **8 大核心仪表与自驾视图矩阵 (8-Page Driving System)**：
  - **Page 1**：核心驾驶主仪表盘（左侧动态圆形罗盘 + 右侧均衡车速 + 底部海拔/里程，支持**长按 TRIP 里程 2 秒全链路行程数据同步归零**）；
  - **Page 2**：海拔高度 1 小时平滑折线图与最高/最低极值；
  - **Page 3**：车速 1 小时平滑折线图与最高时速（坚决不展示无意义最低时速）；
  - **Page 4**：轻量矢量自驾轨迹与返航地图（远景最小外接矩形自适应全路径贴合 + 近景 5km 弯道跟随）；
  - **Page 5**：车辆动态 G-Force 摩擦力靶图 + 越野姿态俯仰/侧倾水平仪 + 道路真实坡度百分比（+7.5% 陡坡）；
  - **Page 6**：当前 GPS 坐标逐小时天气预报（未来 24 小时温度折线 + 逐小时降水概率柱状条 + 离线长效缓存）；
  - **Page 7**：多时区世界时钟（2×2 四宫格卡片，支持单点修改卡片：GPS 经度自适应定位 vs 区域城市 38px 大热区免打字点选，向上滑 Swipe Up 撤销）；
  - **Page 8**：动态 4 宫格工具箱（TF 管理/Wi-Fi管理/GPS详情/系统设置与电量能量监测，全层级向上滑动 Swipe Up 一键直达主仪表）。
- **全黑夜视 UI 主题 (Pure Dark Theme)**：全界面纯黑背景（`#000000`），高对比度荧光青/绿色文字指示，夜间行驶零眩光。
- **双流并行 GPX 轨迹落盘 (WGS-84 + GCJ-02)**：
  - 每秒同时写入 `W-yyyymmdd-hhmmss.gpx` 与 `C-yyyymmdd-hhmmss.gpx`；
  - **整 1 小时（3600 点）严格连续切片**，合并无缝贴合；
  - **4 级断电防护**：XML 实时预封口、10秒定时 `file.sync()`、开机自动扫描未闭合标签并修复；
  - **静止零漂死区冻结**：车速 $<1.8\text{km/h}$ 停止写入，杜绝红灯原地慢飘与毛线团；
  - **极限跳变过滤**：速度 $>180\text{km/h}$ 或加速度 $>1.2\text{G}$ 的畸变点强制丢弃。
- **电源管理与自启机制**：
  - 点火随车自动秒级冷启；接常通电时停稳 15 分钟自动封口停录；装底座后支持断电倒计时与超低功耗休眠（$<35\mu\text{A}$）。
- **局域网/热点无线轨迹导出**：
  - 在 Page 8 工具箱中一键开启专属直连热点（`M5Track-Share`），手机连接直接访问 Web 页面下载 GPX，标注双坐标系分类，即走即关。
