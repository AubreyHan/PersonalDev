## 4. 3D 打印与切片建议 (Bambu Studio / 拓竹推荐)

* **推荐耗材**：**PETG** 或 **ABS / ASA**
  > **特别注意**：车载环境夏季暴晒中控台温度可达 65℃ 以上，普通 PLA 耗材耐温仅 50~55℃ 会发生软化形变。**强烈建议使用 PETG（耐温 ~75℃）或 ABS/ASA（耐温 90℃+）**。
* **摆放方向**：底面朝下平放在热床上（无需翻转）。
* **支撑设置**：**无需任何支撑 (No Support Required)**，所有开口均为开敞式垂直槽。
* **层高 (Layer Height)**：`0.20mm Standard`（兼顾速度与外观强度）。
* **墙层数 (Wall Loops)**：`4` 或 `5` 圈（壁厚充足，结构极其坚固）。
* **填充率 (Infill)**：`20% ~ 25%`（推荐使用 `Gyroid` 陀螺仪填充，抗振消音性能极佳）。
* **底座固定推荐**：打印完成后，底面粘贴 2 条汽车专用 3M VHB 泡棉双面胶，贴在车内平整位置即可。
